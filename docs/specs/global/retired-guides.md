# Retired guides and the new page groups

**Decision (maintainer, 2026-11-15):** the site was still mostly a dementia library (79 of 88 English guides and 10 of 12 game pages were titled for dementia). It now follows MISSION.md: creative activities for anyone caring for someone else. The maintainer chose to:

1. **Retire most dementia guides and redirect them** (not reframe them in place).
2. **Build four new page groups now**: Crafts, Kids, Together, Creative calm. This overrides the roadmap's evidence gate for S2 and S3 expansion (§3 of [18-roadmap.md](18-roadmap.md)).
3. **Keep translations live** until they are re-translated and reviewed.

## What changed

| | Before | After |
|---|---|---|
| English guides | 88 (79 about dementia) | 14 kept + 27 new |
| Sections | activities, caregiving, brain-health | activities, crafts, kids, together, creative-calm, caregiving (brain-health retired in English) |
| Main navigation | Home, Find, Games, Activities, Caregiving, Brain health | Home, Find, Crafts, Kids, Together, Creative calm, Games |

**Kept (14):** the nine guides that already fit the mission (art supplies, art therapy explained, creative arts therapies, painting to relax, finding an art therapist, group art, pen pals, relaxing art, reminiscence activities), plus five dementia pages that are about doing activities: `activities/ideas`, `activities/late-stage`, `caregiving/how-to-play-together`, `caregiving/when-they-say-no`, `caregiving/after-dementia-diagnosis`. The `/dementia-activities/` hub stays as the one place for dementia-specific activity help.

**Retired (74) and the brain-health section:** the map is `site/src/lib/retired-guides.ts`. Each old English address gets one permanent (301) redirect, with and without the trailing slash, in `site/public/_redirects` (generated by `pnpm gen:redirects`; a test fails if the file and the map disagree). Rules used:

- A dementia activity guide → the new page that covers the same activity for everyone (e.g. coloring → `/crafts/coloring-pages-for-adults/`), or the kept dementia idea list when the topic only makes sense for dementia (stages, early onset).
- A brain-health research guide (prevention, diet, sleep) → `/dementia-activities/`; it was off-mission (not an activity) and the riskiest for claims.
- A dementia care-advice guide (bathing, money, medication) → `/caregiving/after-dementia-diagnosis/`, which points to trusted organizations, or to a new page where one fits (self-care, visiting, late afternoon).
- No redirect points to another retired page (tested).

**Translations:** retired guides keep their Markdown files, so the translated versions (about 130 languages) stay live and listed in their language's section pages. Only the English page is replaced. Translated pages no longer list an English alternate for a retired guide. To remove the translations later, delete the retired English files and their `guides-i18n` copies together; the redirects stay.

**Links:** every reference to a retired guide (related guides, hub and card guide lists) resolves to its new page at build time (`resolveGuide` in `site/src/i18n/guides.ts`).

- New sections have no translations; other languages show the English page.
