กิจกรรมเพื่อการรับสัมผัสใช้ประสาทสัมผัสด้านการสัมผัส กลิ่น เสียง และการมองเห็น เราไม่รวมการลิ้มรส ดังนั้นจึงไม่มีอะไรในกิจกรรมเหล่านี้ที่ตั้งใจให้กิน กิจกรรมเหล่านี้เป็นประสบการณ์ง่ายๆ ที่สร้างขึ้นทีละประสาทสัมผัส เช่น การลูบผ้าพันคอนุ่มๆ การดมกลิ่นสะระแหน่ หรือการฟังเสียงฝน นี่คือกิจกรรมสร้างสรรค์ ไม่ใช่การบำบัดรักษา การตรวจสอบความปลอดภัยเพียงไม่กี่ข้อจะช่วยให้ทุกคนผ่อนคลายได้มากขึ้น หากคุณหรือผู้ที่คุณดูแลมีปัญหาสุขภาพ เช่น การกลืนลำบาก โรคผิวหนัง หรืออาการแพ้ โปรดปรึกษาแพทย์ประจำตัวหรือผู้เชี่ยวชาญที่มีใบอนุญาตก่อน

## กิจกรรมนี้เหมาะกับใคร

กิจกรรมเพื่อการรับสัมผัสเหมาะกับผู้ใหญ่ในหลายช่วงของชีวิต เหมาะกับผู้ที่ชอบจับต้องสิ่งของ ผู้ที่มีแรงน้อยและต้องการงานเบาๆ และผู้ที่ใช้เวลาส่วนใหญ่ของวันบนเก้าอี้หรือบนเตียง นอกจากนี้ยังทำร่วมกันข้ามวัยได้ เช่น เด็กและผู้ใหญ่จับตะกร้าผ้าชิ้นเดียวกัน นี่เป็นเพียงข้อเสนอแนะ ไม่ใช่การวินิจฉัย

## ต้องเตรียมอะไรบ้าง

- ตะกร้าหรือกล่องสำหรับใส่สิ่งของ มีฝาปิดหากต้องการให้เป็นระเบียบ
- สิ่งของขนาดใหญ่และปลอดภัย เช่น ผ้าสี่เหลี่ยมนุ่มๆ ช้อนไม้ หินเรียบ หรือกิ่งสมุนไพร
- โลชั่นที่ไม่มีกลิ่นหรือมีกลิ่นอ่อน หากผิวไม่มีปัญหาและผู้นั้นไม่แพ้
- ห้องเงียบ ปิดโทรทัศน์
- ผ้าอุ่นๆ น้ำหนึ่งแก้ว และเก้าอี้ให้ผู้นั้นนั่ง

## ไอเดียกิจกรรมแยกตามประสาทสัมผัส

**การสัมผัส**

- **นวดมือ** ผสมโลชั่นที่ไม่มีกลิ่นเล็กน้อยให้อุ่นในมือ แล้วลูบช้าๆ จากข้อมือถึงปลายนิ้ว การ์ด [นวดมือ](/activity/give-a-hand-massage/) มีขั้นตอนให้ทำตาม
- **ตะกร้าผ้า** ผ้าสี่เหลี่ยมขนาดใหญ่ เช่น กำมะหยี่ ผ้าคอร์ดูรอย ผ้าฟลีซ ผ้าซาตินและขนแกะ ให้ลูบและพับ การ์ด [ทำแผ่นพื้นผิว](/activity/make-a-texture-board/) นำแนวคิดเดียวกันนี้มาทำเป็นของที่เก็บไว้ได้
- **พับและจัดเรียง** ผ้าขนหนูเล็กหรือผ้าเช็ดปากที่สะอาด ให้พับ วางซ้อน และพับใหม่ การ์ด [พับผ้าขนหนูด้วยกัน](/activity/fold-towels-together/) เป็นงานที่ทำต่อเนื่องได้เรื่อยๆ
- **ผ้าอุ่น** ผ้าชุบน้ำอุ่นหมาดๆ สำหรับมือในวันอากาศหนาว ทดสอบอุณหภูมิที่ข้อมือของคุณก่อน

**กลิ่น**

- **สมุนไพรสด** ถูใบสะระแหน่ โรสแมรี หรือโหระพาระหว่างนิ้ว แล้วเอาไปไว้ใกล้จมูก
- **กลิ่นในครัว** กลิ่นกาแฟที่กำลังชง ขนมปังที่กำลังปิ้ง หรือการปอกส้มใกล้ๆ
- **ลาเวนเดอร์แห้ง** ถุงผ้าเล็กๆ ที่เย็บปิดแล้ว การ์ด [ทำถุงลาเวนเดอร์](/activity/make-a-lavender-sachet/) แสดงวิธีทำ

**เสียง**

- **เพลงที่ชอบ** เพลงคุ้นหูที่เปิดเสียงเบาๆ ดูเพิ่มเติมที่ [เพลงเพื่อความสงบและความผูกพัน](/creative-calm/music-for-calm-and-connection/)
- **เสียงธรรมชาติ** เสียงฝน เสียงคลื่น หรือเสียงนกร้อง เปิดเบาๆ
- **กรับเขย่า** การ์ด [ทำกรับเขย่าปิดผนึก](/activity/make-a-sealed-shaker/) ช่วยทำกรับที่ปลอดภัยไว้เล่นตามเพลง

**การมองเห็น**

- **มองออกไปนอกหน้าต่าง** ที่ให้นกมากินอาหารนอกหน้าต่าง หรือวิวถนน การ์ด [ดูนกจากหน้าต่าง](/activity/watch-birds-from-a-window/) มีไอเดียเพิ่มเติม
- **สีและลวดลาย** แยกกระดุมหรือเศษผ้าตามสี ด้วยการ์ด [แยกกระดุมตามสี](/activity/sort-buttons-by-color/) เลือกใช้เฉพาะกระดุมขนาดใหญ่
- **ดอกไม้** การ์ด [จัดดอกไม้ด้วยกัน](/activity/arrange-flowers-together/) เป็นวิธีที่อ่อนโยนในการจับ ดู และดมดอกไม้สด

## ทำกล่องรับสัมผัสอย่างไร

1. เลือกธีมที่เชื่อมโยงกับชีวิตของผู้นั้น เช่น ชายหาด สวน ครัว งานช่าง หรือการเย็บปักถักร้อย
2. เลือกสิ่งของขนาดใหญ่และปลอดภัยห้าถึงหกชิ้น เช่น เปลือกหอยขนาดใหญ่ ช้อนไม้ ผ้าพันคอนุ่มๆ ถุงลาเวนเดอร์ที่ปิดผนึกแล้ว หรือบล็อกไม้เรียบ
3. ตรวจสอบทุกชิ้นว่าไม่มีชิ้นส่วนเล็ก ไม่มีขอบคม ไม่มีด้ายหลุด และไม่มีของที่แตกง่าย
4. หยิบออกมาทีละชิ้น ยื่นให้ อธิบายสิ่งนั้น และให้ผู้นั้นสำรวจเอง
5. เก็บกล่องหลังใช้งาน และตรวจสิ่งของอีกครั้งก่อนใช้ครั้งต่อไป

## ทำกับผู้สูงอายุหรือผู้ที่เป็นภาวะสมองเสื่อม

กิจกรรมเพื่อการรับสัมผัสมีความสำคัญมากที่สุดในระยะท้ายของภาวะสมองเสื่อม [สมาคมอัลไซเมอร์](https://www.alz.org/help-support/caregiving/stages-behaviors/late-stage) ระบุว่าในระยะนี้ ผู้ป่วยรับรู้โลกผ่านประสาทสัมผัสเป็นหลัก และคุณสามารถแสดงความห่วงใยผ่านการสัมผัส เสียง การมองเห็น การลิ้มรส และกลิ่นได้ [NHS](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/) แนะนำว่ากิจกรรมในระยะท้ายมักเน้นประสาทสัมผัส เช่น การเปิดเพลง การจับสิ่งของ และการนวดมือ

เข้าหาจากด้านหน้า เรียกชื่อผู้นั้น และถามหรือบอกก่อนสัมผัส เช่น "ฉันมีโลชั่นอยู่ อยากให้ช่วยนวดมือไหม" ให้ทีละอย่าง สังเกตสีหน้าที่อ่อนลง มือที่คลายตัว หรือรอยยิ้ม หากดึงมือกลับ ขมวดคิ้ว หรือกระสับกระส่าย ให้หยุด ควรจำกัดเวลาไว้ประมาณห้านาทีที่สงบ

## ข้อควรระวังด้านความปลอดภัย

กิจกรรมเพื่อการรับสัมผัสค่อนข้างอ่อนโยน แต่ความเสี่ยงบางอย่างสำคัญ โดยเฉพาะกับผู้ที่อาจเอาของเข้าปาก หรือมีปัญหาการกลืน

| ความเสี่ยง | สิ่งที่ควรทำ |
| --- | --- |
| การสำลัก | ใช้เฉพาะสิ่งของที่ใหญ่เกินกว่าจะกลืนได้ ไม่ใส่กระดุม ลูกปัด เหรียญ หรือของเล่นชิ้นเล็กไว้ในกล่องโดยไม่ปิด |
| สิ่งที่ดูเหมือนอาหาร | หลังใช้งาน เก็บโลชั่น สบู่ แชมพู หรือน้ำหอมให้มิดชิด เพราะอาจดูหรือมีกลิ่นเหมือนอาหาร และควรเอาผลไม้ปลอมออก |
| อาการแพ้ | ตรวจสอบอาการแพ้ต่อถั่ว ยางพารา ขนแกะ พืช หรือกลิ่นหอมก่อนเริ่ม |
| กลิ่นแรง | หลีกเลี่ยงน้ำหอมกลิ่นแรงและน้ำมันหอมระเหย โดยเฉพาะผู้ที่เป็นหอบหืดหรือมีปัญหาการหายใจอื่นๆ กลิ่นอ่อนจากธรรมชาติปลอดภัยกว่า |
| ผิวหนัง | ตรวจดูผิวที่เป็นแผล ถลอก หรือบอบบางก่อนนวด ใช้แรงกดเบาๆ และหยุดหากผู้นั้นทำหน้าเจ็บ |
| อุณหภูมิ | ทดสอบผ้าอุ่นและเครื่องดื่มร้อนที่ข้อมือของคุณก่อน |
| สิ่งของที่คมหรือเป็นพิษ | ไม่ใช้เครื่องมือมีคม แก้ว หรือวัสดุงานฝีมือที่เป็นพิษ |

## อโรมาเธอราพีช่วยได้ไหม

น่าจะไม่ช่วยในทางที่วัดผลได้ การวิเคราะห์ของ [Cochrane เรื่องอโรมาเธอราพีสำหรับภาวะสมองเสื่อม](https://www.cochrane.org/evidence/CD003150_aromatherapy-dementia) พบ 13 การศึกษา มีผู้เข้าร่วม 708 คน ทั้งหมดอาศัยอยู่ในสถานดูแลผู้สูงอายุ การศึกษาเหล่านั้นมีขนาดเล็ก ผลลัพธ์ไม่ไปในทิศทางเดียวกัน และไม่พบหลักฐานว่าได้ผลในผลลัพธ์ที่การวิเคราะห์นี้ศึกษา หากผู้นั้นชอบกลิ่นอ่อนๆ ที่คุ้นเคย เช่น ลาเวนเดอร์จากสวน ก็เป็นเหตุผลที่ดีในการแบ่งปันกลิ่นนั้น แต่ไม่ใช่การรักษา

## ทางเลือกที่ใช้สิ่งเร้าน้อย

บางคนรู้สึกเหนื่อยเมื่อได้รับสิ่งเร้ามาก ทางเลือกที่ใช้สิ่งเร้าน้อยใช้สิ่งของเพียงชิ้นเดียว แสงนุ่มๆ ผ้าห่มอุ่นๆ และไม่มีกลิ่น นั่งด้วยกันแล้วปล่อยให้แสงเคลื่อนไปบนผนัง หรือถือหินเรียบไว้หนึ่งก้อน พูดคุยด้วยเสียงเบาและเว้นจังหวะพักเมื่อใดก็ได้ หากผู้นั้นหันหน้าหนีหรือหลับตา นั่นก็ถือว่าเป็นกิจกรรมที่สมบูรณ์แล้ว

## เมื่อไม่ได้ผล

หากผู้นั้นดูไม่สบายใจ ให้หยุด เก็บสิ่งของไว้ และนั่งเงียบๆ ด้วยกัน ลองประสาทสัมผัสอื่นในวันอื่น หรือลองในช่วงเวลาอื่นของวัน บางคนชอบช่วงเช้า ส่วนบางคนชอบตอนค่ำเมื่อบ้านเงียบ การหยุดก่อนเวลาถือเป็นผลลัพธ์ที่ดี

การหยุดพัก[การหายใจอย่างสงบ](/games/calm-breathing/) เป็นวิธีที่อ่อนโยนในการจบกิจกรรม โดยหายใจช้าๆ คนละหนึ่งครั้ง โดยไม่มีแรงกดดันให้ทำอะไรเพิ่ม
