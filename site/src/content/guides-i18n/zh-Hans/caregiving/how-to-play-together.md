与认知症长者一起玩游戏，不应该像比赛。它应该像两个人靠得很近地坐着，一起指着图片，为一句俗语笑出来，并聊起任何冒出来的话题。游戏只是两个人共处的一个理由。

本指南说明如何做好准备、如何掌控游戏节奏、出现“不对劲”时该说什么、如何让任何游戏变得简单一些或稍微有些挑战，如何把游戏变成交谈，以及如何判断该停下的时候。它适用于我们的[游戏](/games/)，也适用于你手边已有的卡片、拼图和桌游。

## 与认知症长者玩游戏，最好的方式是什么？

重点是享受，而不是成就。这是 Alzheimer's Association [关于活动的指导](https://www.alz.org/help-support/caregiving/daily-care/activities)的核心建议：以对方仍然保有的能力为基础，帮助他们开始，困难的部分由你来完成，并且不要批评或纠正无害的活动。

具体来说：

- **坐在对方身边，而不是对面。** 并肩而坐，你们都能看到屏幕或桌面，帮忙也会像一起合作，而不是在监督。
- **一次只提供一个游戏。** 一连串的选项，在开始之前就会让人觉得像在考试。
- **跟随对方的引导。** 如果他想按自己的顺序点图片，花十分钟谈论同一张图片，或者只玩两轮就停下，那就是今天的游戏。
- **记录美好的时刻，而不是完成的局数。** 一个微笑、一个故事或一段平静的半小时，才是你所期待的结果。

## 开始之前应该如何准备？

几分钟的准备，可以避免大部分本该归咎于游戏本身的挫折。

1. **选择对方状态最好的时段。** [美国国家老化研究所（NIA）关于调整活动的指南](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease)建议，把外出和活动安排在对方状态最好的时段。对很多人来说，那是上午中段。傍晚通常更难，请参阅[傍晚的平静活动](/creative-calm/calm-afternoon-activities/)。
2. **让房间安静。** 关掉电视和收音机，如果可以，关上门。[家庭照护者联盟（Family Caregiver Alliance）](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)建议，在开口交谈之前先减少噪音和干扰。
3. **先确认舒适度。** 身边放一杯饮品，事先去过洗手间，坐一把舒适的椅子，并戴好眼镜和助听器。
4. **把空间照亮。** 明亮而均匀的光线，并且屏幕上不要有反光，图片会更容易看清。
5. **坐下之前把游戏准备好。** 先打开游戏，选好设置，自己调好音量，然后再把屏幕转向对方。如果有帮助，可以在设备上开启更大的字体。
6. **把设备架起来。** 用支架或保护套把平板竖立起来，这样就没有人需要一直拿着它，指点起来也更方便。

## 如何在没有压力的情况下邀请对方？

邀请要随意，并且让对方容易拒绝。以下几句话通常效果不错：

- “我找到了一些花园的图片，要不要和我一起看看？”
- “你能帮我看看这个拼图吗？我卡住了。”
- “今天你想看花还是看鸟？”（两个选项比开放式问题更容易回答）
- “我在给你姐姐做一张卡片。这个应该用什么颜色？”

Alzheimer's Association 建议说明活动的目的，例如为朋友做一张卡片，因为有了理由，活动才有意义。请对方帮忙也很有效，因为这让对方觉得自己有用。

如果对方说不，就接受。稍后再试，或提供别的东西。我们的指南[当对方说不时该怎么办](/caregiving/when-they-say-no/)有更详细的说明。

## 游戏应该持续多久，节奏应该多快？

让对方决定节奏，并计划短时间的游戏。对于共同游戏，并没有经过证据验证的理想时长。两到五分钟的平静时光，本身就可以是一次完整的活动。

- **比你觉得自然的时间等得更久。** NIA 建议，要给对方更多时间来回应，并尽量不要打断。在帮忙之前，先在心里数到十。
- **一次一步。** 给出一个简短的指令（“点一张图片”），然后等待。多示范，少解释：用手指指向应该点的地方。
- **随时可以暂停。** 如果对方停下来谈论某张图片，游戏可以等一等，不必着急。
- **让对方看着。** NIA 指出，有些人更喜欢观看，这是一种正当的选择。

## 我应该纠正错误的答案吗？

不应该。一次又一次温和地纠正，会让对方觉得自己做得不好，即使你的本意是好的。Alzheimer's Association 建议，不要批评或纠正无害的活动。在游戏中，几乎每一个错误都是无害的。

| 不要这样说 | 可以这样说 |
| --- | --- |
| “不对，错了。” | “我们换个方法试试。”（NIA 给出的一个例子） |
| “这不是一对，再看看。” | 什么都不说，轮到下一步；或者说“哦，这两张都是红色的。” |
| “你还记得这是谁吗？” | “跟我讲讲这张图片。” |
| “这个你已经做过了。” | “这个很好。我们再做一次。” |
| “拜托，你明明知道的。” | “要不要我把结尾给你看看？” |

如果一个错误明显让对方受挫，就悄悄帮一把。指向正确的图片，自己替他走一步，或在下一轮降低难度。如果一句俗语被接成了有趣的错误结尾，就跟着一起笑。也许他的结尾比原来的还好。

## 如何让游戏变得简单或有挑战？

根据当天对方的状况来调整游戏，而不是根据某个阶段的标签。同一个人，傍晚可能需要比早上更简单的版本。NIA 的第一条建议是，让活动与对方能做到的事情相配，并确保对方感到成功。

| 游戏 | 降低难度 | 稍微增加难度 |
| --- | --- | --- |
| [图片配对](/games/picture-pairs/) | 从4个方块开始，并让图片保持可见 | 增加方块，或在感觉舒适时把图片藏起来 |
| [找出相同](/games/find-the-same/) | 2个选项 | 最多4个选项 |
| [一起分类](/games/sort-together/) | 你拿着图片，对方指出该放的篮子 | 对方自己同时点击图片和篮子 |
| [图片拼图](/games/picture-puzzle/) | 4块拼图，先谈论整张图片 | 9块拼图 |
| [接下句](/games/finish-the-saying/) | 展示结尾，然后一起说 | 让对方先说出结尾，再点击 |
| [找词游戏](/games/word-search/) | 打印出来，一起找一个词，指向它的第一个字母 | 让对方选择下一个要找的词 |
| [涂色](/games/coloring/) | 你选两种颜色，让对方在其中选择 | 让对方选择所有的颜色 |
| [谈话卡](/games/conversation-cards/) | 只是一起看看图片 | 使用卡片上开放式的提示 |
| [照片配对](/games/photo-pairs/) | 几张大家喜爱的家庭照片 | 增加更多照片 |
| [图片宾果](/games/picture-bingo/) | 一名帮手坐在每位玩家身边 | 玩家自己在卡片上做标记 |
| [平静呼吸](/games/calm-breathing/) | 只是一起坐着看 | 跟着缓慢地呼吸 |

游戏太难的迹象：长时间的停顿看起来更像担忧而不是思考，反复说“我不行”，把设备推开，或者错误让对方不安。游戏可能太简单的迹象：无聊，或者对方说这很幼稚。如果出现这种情况，请尊重对方的感受，换成更成熟的活动，例如找词游戏、真实照片的拼图，或是谈论他过去工作的一张照片。

## 如何把游戏变成交谈？

把每张图片都当作一个邀请交谈的机会，并把对方说的任何话都当作很好的回答。对很多家庭来说，这是玩游戏最好的部分。

- **问开放式的、没有错误答案的问题。**“你注意到了什么？”“你喜欢哪一个？”“跟我讲讲这样的一间厨房。”
- **先分享自己。**“我奶奶也养过这样的一只狗。”你的故事会让对方更容易分享他的故事。
- **顺着话题走。** 如果一张汽车的图片引出了一段公路旅行的故事，那么这个故事本身就是活动。让游戏暂停。
- **不要核对事实。** 在回忆交流中，愉快的交谈比准确的细节更重要。如果故事和上次不一样，就享受这个新版本。
- **使用内置的提示。**[接下句](/games/finish-the-saying/)会在每句俗语后面给出谈话提示，[谈话卡](/games/conversation-cards/)正是为此设计的。[照片配对](/games/photo-pairs/)使用你自己的家庭照片，这往往能引出最丰富的故事。

更多点子可参阅我们的[回忆活动指南](/activities/reminiscence/)。如需确诊后的支持，请参阅[确诊后的最初几步](/caregiving/after-dementia-diagnosis/)。

## 什么时候应该停下？

一出现疲倦或不安的第一个迹象就停下，最好再提前一点。Alzheimer's Association 建议，当注意力减退或挫折感上升时，就停下来或换一个活动。

留意以下情况：

- 打哈欠、身体下垂，或目光从屏幕上移开；
- 坐立不安、站起来，或要求离开；
- 叹气、回答简短，或说“我这方面不行”；
- 随意乱点，或把设备推开；
- 流泪、烦躁，或情绪突然变化。

如何妥善地停下：

- **以一件容易的事情结束。** 再让对方完成最后一组配对，或展示最后一张图片让他欣赏。
- **把原因说成是你的。**“我想喝杯茶了。我们就停在这里好吗？”这样就不会让对方觉得自己做得不好。
- **转向体力活动或舒缓的活动。** 短暂散步、吃点东西、叠衣服或听音乐。
- **说些温暖的话。**“我很喜欢和你一起做这个。”不要因为“做对了”而表扬，只表达共处时光的快乐。

提早结束、改变计划，或者放下游戏，只是和对方坐在一起，都是很好的结果。

## 可以在小组或视频通话中玩吗？

可以，只是需要多做一点准备。在小组中，人数保持在几个人，把帮手安排在需要帮助的人身边，并选择一个有清楚共同焦点的游戏。[图片宾果](/games/picture-bingo/)提供可打印的卡片，并有屏幕上的叫号功能，适合小组。更多信息请参阅[养老院小组活动](/crafts/craft-group-sessions/)。

在视频通话中，通话的那一方可以描述一张图片，而房间里的人则负责指点和点击。通话要简短，内容要熟悉。我们的[电话和视频通话指南](/together/staying-connected-from-afar/)有更多建议。

## 如果某个游戏就是不奏效怎么办？

有些日子什么都不奏效，这并不说明你或对方有什么问题。把游戏收起来，换一个时段，换一个游戏，或者干脆不玩。许多好的活动与屏幕毫无关系：音乐、叠毛巾、一起翻看相册，或者一次短暂的散步。更多想法请参阅我们的[活动点子](/activities/ideas/)。
