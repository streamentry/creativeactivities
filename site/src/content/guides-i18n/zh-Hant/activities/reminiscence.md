懷舊就是一起享受過去。對許多患有失智症的長輩來說，幾十年前的回憶，往往比今天早上發生的事更清楚。照片、熟悉的物品、音樂和故事，可以打開這些回憶，也能讓您有溫暖的內容可以分享。只有一條規則：這是一場對話，絕不是一場考試。

## 什麼是懷舊？它和考問有什麼不同？

懷舊是按照長輩自己的速度，透過照片、物品、音樂或影片來分享回憶。[英國國民保健署](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/)把它描述為借助照片、物品、影片或音樂，以書本或平板電腦的形式，分享過去的經歷和故事。考問則不同：它要求對方說出正確的答案，這可能帶來難堪，而不是快樂。

[美國國家老化研究院](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/dos-and-donts-communicating-person-who-has)把詢問對方是否記得某件事或某個人，列為應該避免的做法。[家庭照顧者聯盟](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)建議避開需要短期記憶的問題，改談比較久遠的過去。

| 不要這樣說 | 可以這樣說 |
| --- | --- |
| 「您記得這個嗎？」 | 「看起來是很快樂的一天。跟我說說吧。」 |
| 「這是誰？」 | 「這是玫瑰阿姨在海邊。看那頂帽子。」 |
| 「這是哪一年？」 | 「這看起來是老房子。住在那裡是什麼樣子？」 |
| 「不對，那不是比爾，是法蘭克。」 | 「他看起來很好玩。」 |
| 「您已經跟我說過了。」 | 「我很喜歡那個故事。」 |

## 怎麼聊照片而不考問？

先說您看到的內容，然後留一些空間，讓長輩想補充就可以補充。

1. **並肩坐著。** 把相簿放在你們中間，一起看，而不是隔著桌子像在考試。
2. **挑幾張照片。** 五張好照片，比整盒的照片更好。大張、清晰的照片效果最好。
3. **由您來說出人名。** 「這是您和爸爸在婚禮那天」，可以消除壓力。
4. **評論細節。** 衣服、車子、食物、天氣、臉孔。「好漂亮的車子，看起來亮亮的。」
5. **邀請，不要要求。** 「跟我說說……」或「您注意到什麼？」沉默也沒關係。
6. **順著他的話題。** 如果他完全轉到別的事情，就跟著他走。
7. **在愉快時停下。** 在疲累出現之前，就把相簿闔上。

想要現成的圖片提示，可以試試[對話卡](/games/conversation-cards/)。若想把自己的家庭照片變成溫和的配對遊戲，可以試試[照片配對](/games/photo-pairs/)；您選的照片會留在您的瀏覽器裡。

## 怎麼做一個記憶盒？

記憶盒是一個盛裝長輩生活物品的容器，可以拿在手上，一起談論。

1. **選一個堅固的盒子**，容易打開即可，例如鞋盒、帽盒或小木箱。
2. **選一個主題或混合的內容。** 工作、嗜好、某個地方、某一個十年，或什麼都放一點。
3. **收集安全的物品。** 開始時，五到十件就很足夠。
4. **珍貴的東西用複本。** 無法替代的照片和文件，複製一份，並把原件好好收起來。
5. **一次拿出一件。** 交給他一件，說說它的事，看談話會往哪裡走。

可以放的點子：

- **工作：** 名牌、小工具、制服上的徽章、帳簿、護士胸針，或小餐館的食譜書。
- **家裡：** 他親筆寫的食譜卡、一條茶巾、他喜愛的圍巾或領帶。
- **嗜好：** 沒有鉤子的釣魚假餌、一顆棒球、一團毛線、一包種子。
- **地方：** 明信片、地圖、旅遊紀念品，或家鄉報紙的剪報。
- **家人：** 照片的複本、孩子的畫、婚禮請帖。

不要放尖銳的東西、可能被吞下的小東西，以及可能勾起痛苦回憶的物品，除非您確定對方願意。

## 怎麼做人生故事書？

人生故事書是一本簡單的相簿，附上照片和關於長輩生活的簡短說明。它是一起翻看的東西，也能幫訪客和照護人員看見這個完整的人。

1. **選擇形式。** 附有透明保護套的活頁夾、印製的照片書，或平板電腦上的幻燈片。
2. **規劃幾個章節。** 童年、學校、工作、家人、住過的地方、信仰、嗜好、喜愛的食物和音樂。
3. **每頁放一到兩張照片**，並附上簡短、大字的說明：「瑪麗，22 歲，開始在銀行上班。」
4. **寫下喜好與作息。** 「咖啡要加牛奶。喜歡週日的聖詩。不喜歡太吵的電視。」這能幫助所有照顧他的人。
5. **讓他參與，但依他的意願。** 可以選照片、說故事，或只是看著它慢慢完成。
6. **持續增加內容。** 不必做完才有用。

## 更多懷舊點子

- **播放他年輕時的音樂**，聊聊它帶他去了哪裡。請參閱[音樂活動](/creative-calm/music-for-calm-and-connection/)。
- **看家庭影片或他最喜歡年代的電視節目。**
- **做一道童年的菜**，讓香味帶領對話。
- **看一張家鄉的地圖**，順著熟悉的街道指一指。
- **翻閱舊目錄或雜誌**，聊聊價格、流行和汽車。
- **經他同意後，用手機錄下他的故事**，留給家人。
- **通話時分享。** 視訊時舉起一張照片；請參閱[電話與視訊通話](/together/staying-connected-from-afar/)。
- **探望時帶一張照片或一件物品。** 它能讓探望有一個容易的焦點；請參閱[探望](/together/visiting-someone-in-care/)。

## 如果某段回憶令人痛苦怎麼辦？

有些回憶會帶來悲傷、遺憾或恐懼。如果長輩變得難過，就停下來，安慰他，並溫和地轉換話題或活動。不要爭論當時發生了什麼。家庭照顧者聯盟建議不要試著說服對方他說錯了，而是回應他表現出來的感受，那些感受是真實的。如果他談起已經過世的人，像那人還活著一樣，就回應那份感受：「您很想念她。跟我說說她吧。」

## 研究怎麼說？

[Cochrane 對懷舊療法的回顧](https://www.cochrane.org/evidence/CD001120_reminiscence-therapy-dementia)涵蓋 22 項試驗、1,972 人，發現其效果不一致，且幅度小，並依環境與形式而異。它沒有發現對失智症患者有傷害的證據。我們建議懷舊，是因為它能帶來溫暖、有意義的相處時光，而不是把它當成治療。想了解更多容易的對話方式，請參閱[確診後的第一步](/caregiving/after-dementia-diagnosis/)。
