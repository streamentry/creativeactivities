對長者來說，小型又省錢的工具組比完整的畫室好用，而且大多數人只需要十樣左右的用品。本頁列出應該購買的項目、便宜的替代品、關節炎、視力微弱與臥床作畫時的調整方式、應避免的東西，以及如何收納，讓工具組隨時都能派上用場。

## 基本藝術工具組應該包含什麼？

下表列出核心用品。每一樣都很常見、價格不高，而且能用在許多活動中。替代品都是一般折扣店或五金行就能買到的東西。

| 用品 | 用途 | 低成本替代品 |
| --- | --- | --- |
| 粗毛筆，1 英吋或更寬 | 筆觸大，容易握持 | 泡棉畫筆 |
| 水彩盒，12 色 | 顏色即用，不必調色 | 自有品牌的水彩盒或幾支水彩管 |
| 厚紙，140 lb 或 300 gsm | 吸水時不易起皺 | 厚卡紙或綜合媒材紙本 |
| 膠棒 | 乾淨、不滴膠的黏合方式 | 任何無毒膠棒 |
| 軟鉛筆，2B 或 4B | 輕輕一劃就有深色線條 | 一般石墨鉛筆 |
| 油性粉蠟筆 | 色彩豐富，不需要水或畫筆 | 粗蠟筆 |
| 可風乾黏土 | 可捏塑成形，不需要窯燒 | 標示無毒的造型黏土 |
| 遮蔽膠帶 | 固定紙張，不讓它移動 | 美工遮蔽膠帶 |
| 有邊的托盤 | 把用品放在一起，也能接住溢出的液體 | 有邊的烤盤 |
| 圍裙或舊棉質襯衫 | 保護衣物 | 反穿的舊襯衫 |

購買膠水、黏土和顏料時，請檢查標籤上的過敏原，並留意是否有無毒標示。像 [撕紙拼貼](/activity/tear-paper-mosaic/) 和 [用水彩作畫](/activity/paint-with-watercolors/) 這樣的活動卡片，只需要用到上述這些基本用品。

## 關節炎、視力微弱或臥床時，有哪些調整方式？

**關節炎。** 用泡棉膠帶包住握把，讓握把變粗、比較好抓。選擇輕巧的畫筆和馬克筆。用夾子或膠帶固定紙張，這樣本人就不必用力壓住。把前臂靠在桌面上做支撐。

**視力微弱。** 使用高對比的顏色，例如白紙上用黑色馬克筆，主題要大膽、簡單，像是一朵花。把良好的檯燈放在側邊，以減少眩光。[一起插花](/activity/arrange-flowers-together/) 這張卡片附有適合視力微弱者的版本。

**臥床作畫。** 使用膝上托盤，或把畫板靠在枕頭上。在紙下方放一片防滑墊。可以夾在床頭或架子上的小夾燈會有幫助。工具只留幾樣，例如油性粉蠟筆、膠棒和一張可以作畫的卡紙。

## 應該避免什麼？

- 亮片、散落的珠子和小貼紙，這些東西可能被放進嘴裡。
- 溶劑型顏料、噴膠和亮光漆，除非空間通風良好。
- 美工刀和熱熔膠槍。切割的工作請自己事先完成。
- 容易翻倒的開口液體瓶罐。
- 印有卡通圖案的兒童美術組。許多成年人會不喜歡。
- 過大的工具組，讓人覺得一定要全部用完。

## 如何收納，讓工具組一分鐘內就能用？

所有東西都放進一個透明、有蓋的盒子或托盤。把畫筆筆毛朝上插在杯子裡。鉛筆和粉蠟筆放在鞋盒的一個隔間，紙張平放在盒蓋下方。把盒子放在方便拿取、不會擋到路、寵物和幼童碰不到的地方。每個月檢查一次黏土和顏料，把已經乾掉的換掉。在盒蓋內側貼一張簡短的清單，讓任何人都能看出缺了什麼。要開始畫的時候，把托盤提出來，就可以開始了。
