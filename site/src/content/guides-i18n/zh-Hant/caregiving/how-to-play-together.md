和失智長輩一起玩的好遊戲，看起來不像比賽。它看起來像兩個人靠得很近，一起指著圖片，為一句俗語笑出來，然後聊起任何冒出來的話題。遊戲只是一個讓彼此共度時光的理由。

本指南說明如何準備、如何掌握遊戲的節奏、當事情「出錯」時該說什麼、如何讓任何遊戲變簡單或稍微有挑戰性、如何把遊戲變成聊天，以及如何知道什麼時候該停。本指南適用於我們的[遊戲](/games/)，也適用於您手邊已有的卡片、拼圖和桌遊。

## 和失智長輩玩遊戲，最好的方式是什麼？

重點放在享受，而不是達成目標。這是[阿茲海默症協會活動指南](https://www.alz.org/help-support/caregiving/daily-care/activities)的核心建議：從長輩仍然擁有的能力出發，幫他開個頭，困難的部分由您來完成，並且不要批評或糾正無傷大雅的活動。

實際做法包括：

- **坐在他身邊，而不是對面。** 並肩坐下，你們都能看到螢幕或桌面，幫忙會像是一起合作，而不像在監督。
- **一次只提供一個遊戲。** 一堆選項還沒開始就像一場測驗。
- **跟著他的引導走。** 如果他想按自己的順序點選圖片、花十分鐘談論一張圖，或玩了兩輪就停下，那就是今天的遊戲。
- **計算美好的時刻，而不是完成的局數。** 一個微笑、一段故事或一段平靜的半小時，就是您希望得到的結果。

## 開始之前要怎麼準備？

幾分鐘的準備，就能避免大部分人會怪到遊戲本身的挫折。

1. **挑他狀態最好的時段。** [美國國家老化研究院（NIA）的活動調整指南](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease)建議，把外出和活動安排在長輩狀態最好的時段。對很多人來說，那是上午中段。傍晚通常比較難，請參閱[平靜的傍晚活動](/creative-calm/calm-afternoon-activities/)。
2. **讓房間安靜。** 如果可以，請關掉電視和收音機，並關上門。在開口說話之前，[家庭照顧者聯盟（Family Caregiver Alliance）](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)建議先減少噪音和干擾。
3. **先確認舒適。** 手邊放一杯飲料，事先去過洗手間，坐在舒服的椅子上，並戴好眼鏡和助聽器。
4. **把空間照亮。** 明亮、均勻、螢幕上沒有反光的光線，會讓圖片更容易看清楚。
5. **在坐下之前就把遊戲準備好。** 打開遊戲，自己選好設定並調好音量，然後再把螢幕轉向他。如果有幫助，可以在裝置上開啟較大的文字。
6. **把裝置架好。** 用支架或保護套讓平板直立，這樣就不需要有人一直拿著，指認也比較方便。

## 怎麼不帶壓力地邀請他？

邀請的語氣要輕鬆，而且讓對方容易拒絕。以下幾句話通常很有效：

- 「我找到一些花園的圖片，要不要跟我一起看？」
- 「可以幫我看看這個拼圖嗎？我卡住了。」
- 「今天您想看花還是看鳥？」（二選一比開放式問題容易）
- 「我要幫您的妹妹做一張卡片。這張應該用什麼顏色？」

阿茲海默症協會建議說明活動的目的，例如是為朋友做一張卡片，因為有理由，活動才有意義。請對方幫忙也有效，因為這會讓他覺得自己有用。

如果他說不要，就尊重他。過一陣子再試，或提供不同的東西。我們的[當長輩說不要時該怎麼辦](/caregiving/when-they-say-no/)一文有更多說明。

## 遊戲應該玩多久？節奏要多快？

讓長輩決定節奏，並規劃較短的時段。一起玩的遊戲，沒有實證支持的理想長度。平靜的兩到五分鐘，就可以是一個完整的活動。

- **比感覺自然的時間再多等一下。** NIA 建議，要留給對方更多時間回應，並盡量不要打斷。幫忙之前，先在心裡數到十。
- **一次一個步驟。** 給一個簡短的指令（「點一張圖」），然後等待。用示範代替解釋：指給他看該點哪裡。
- **可以隨時暫停。** 如果他停下來談論一張圖片，遊戲可以等一下。不需要趕時間。
- **讓他看著就好。** NIA 指出，有些人比較喜歡看，這是一個值得尊重的選擇。

## 答錯了，要糾正嗎？

不要。一再溫和地糾正，會讓他覺得自己做不好，即使您的出發點是好的。阿茲海默症協會建議，不要批評或糾正無傷大雅的活動。在遊戲中，幾乎每個錯誤都是無傷大雅的。

| 不要說 | 可以試試 |
| --- | --- |
| 「不對，錯了。」 | 「我們試試這樣。」（NIA 提供的例子） |
| 「不一樣喔，再看看。」 | 什麼都不說，直接進行下一輪，或說「喔，這兩張都是紅色的。」 |
| 「您記得這是誰嗎？」 | 「跟我說說這張圖片。」 |
| 「這個您已經做過了。」 | 「這個很好。我們再做一次。」 |
| 「拜託，您知道的。」 | 「要不要我示範最後一步？」 |

如果錯誤明顯讓他沮喪，就安靜地幫忙。指給他看正確的圖片、自己來走一步，或在下一輪讓遊戲變簡單。如果俗語被接成一個好笑的錯誤結尾，就跟著一起笑。他的結尾可能比原本的還好。

## 怎麼讓遊戲變簡單或變難一點？

依照當天的這個人來調整，而不是依照某個階段的標籤。同一個人，晚上可能比早上需要更簡單的版本。NIA 的第一個建議，是讓活動配合對方能做到的事，並確保他感到有成就。

| 遊戲 | 變簡單的方式 | 稍微變難的方式 |
| --- | --- | --- |
| [圖片配對](/games/picture-pairs/) | 從 4 張圖卡開始，並讓圖片一直顯示 | 增加卡片數量，或在感覺舒適時把圖片遮住 |
| [找相同](/games/find-the-same/) | 2 個選項 | 最多 4 個選項 |
| [一起分類](/games/sort-together/) | 您拿著圖片，他指出要放進哪個籃子 | 他自己點選圖片和籃子 |
| [圖片拼圖](/games/picture-puzzle/) | 4 塊拼片，先談論整張圖 | 9 塊拼片 |
| [把話說完](/games/finish-the-saying/) | 先示範結尾，然後一起說出來 | 讓他先說出結尾，再點選 |
| [找字遊戲](/games/word-search/) | 印出來，一起找一個字，指出它的第一個字母 | 讓他選擇下一個要找的字 |
| [塗色](/games/coloring/) | 您先選兩種顏色，他在其中挑選 | 讓他自己選所有的顏色 |
| [聊天卡](/games/conversation-cards/) | 一起看看圖片就好 | 使用卡片上的開放式提示 |
| [照片配對](/games/photo-pairs/) | 幾張家人喜愛的照片 | 增加照片數量 |
| [圖片賓果](/games/picture-bingo/) | 由一位協助者陪坐在每位玩家旁邊 | 玩家自己標記自己的卡片 |
| [平靜呼吸](/games/calm-breathing/) | 就一起坐著看 | 跟著慢慢呼吸 |

遊戲太難的跡象：長時間的停頓，看起來是焦慮而不是在思考；反覆說「我不會」；把裝置推開；或錯誤讓他不安。遊戲可能太簡單的跡象：覺得無聊，或說這很幼稚。如果發生這種情況，請尊重他的感受，改做一些他覺得成熟的事，例如找字遊戲、一張真實照片的拼圖，或談談他以前工作的事。

## 怎麼把遊戲變成聊天？

把每一張圖片當成邀請對方說話的機會，並把他說的任何內容都當成好的回答。對很多家庭來說，這是玩遊戲最好的部分。

- **問開放式、沒有對錯的問題。** 「您注意到什麼？」「您喜歡哪一個？」「跟我說說一個像這樣的廚房。」
- **先分享自己的事。** 「我的奶奶以前也有一隻這樣的狗。」您的故事會讓他更容易分享自己的故事。
- **順著岔開的話題走。** 如果一張汽車的圖片引出一段公路旅行的故事，那段故事就是活動本身。遊戲可以先暫停。
- **不要去核對事實。** 在回憶活動中，愉快的交談比精確的細節更重要。如果故事跟上次不一樣，就享受這個新版本。
- **善用內建的提示。** [把話說完](/games/finish-the-saying/)會在每句俗語後面附上談話提示，而[聊天卡](/games/conversation-cards/)正是為此設計。[照片配對](/games/photo-pairs/)使用您自己的家庭照片，這往往會激發最豐富的故事。

更多點子請參閱我們的[回憶活動指南](/activities/reminiscence/)。如果需要確診後的支持，請參閱[確診後的第一步](/caregiving/after-dementia-diagnosis/)。

## 什麼時候該停？

一出現疲累或不開心的跡象就停下，最好還能再早一點停。阿茲海默症協會建議，當注意力減退或挫折感升高時，就停下或改變活動。

請留意：

- 打哈欠、身體癱軟，或眼睛從螢幕上飄開；
- 坐立不安、站起來，或要求離開；
- 嘆氣、回答很簡短，或說「我很不會這個」；
- 隨意亂點，或把裝置推開；
- 流淚、煩躁，或情緒突然改變。

如何好好地停下：

- **用一件簡單的事作結尾。** 讓他再做一次配對，或最後看一張圖欣賞一下。
- **把理由說成是關於您自己。** 「我想喝杯茶了。我們就在這裡停下好嗎？」這樣就不會暗示他做得不好。
- **轉換成比較有動作或能讓人平靜的事。** 短暫散步、吃點點心、摺衣服或聽音樂。
- **說一句溫暖的話。** 「我很喜歡跟您一起做這個。」不要稱讚「做對了」，只表達相處的時光讓您很愉快。

提早結束、改變計畫，或放棄遊戲，只是一起坐著，都是好的結果。

## 可以在團體或視訊通話中玩嗎？

可以，但需要多一點準備。在團體中，人數請保持在幾人，需要幫忙的人旁邊要有協助者，並選擇一個有清楚共同焦點的遊戲。[圖片賓果](/games/picture-bingo/)提供可列印的卡片，並有螢幕上的唱號功能，適合團體使用。更多資訊請參閱[照護機構團體活動](/crafts/craft-group-sessions/)。

在視訊通話中，通話的另一端可以描述圖片，而房間裡的人則指出和點選。讓通話簡短、熟悉。我們的[電話與視訊通話指南](/together/staying-connected-from-afar/)有更多建議。

## 如果遊戲就是不順利呢？

有些日子怎麼做都沒有效果，這不代表您或他有問題。把遊戲收起來，改天在不同的時段嘗試、換一個遊戲，或乾脆不玩。許多好的活動與螢幕無關：音樂、摺毛巾、翻看相簿，或短暫散步。更多點子請瀏覽我們的[活動點子](/activities/ideas/)。
