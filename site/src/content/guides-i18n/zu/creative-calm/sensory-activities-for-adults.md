Imisebenzi yezinzwa isebenzisa izinzwa zokuthinta, ukunuka, umsindo nokubona. Sishiye ukunambitha, ngakho akukho okwenzelwe ukudliwa kuyo. Yizipiliyoni ezilula ezakhiwe ngenzwa eyodwa ngesikhathi, njengokuzwa isikhafu esithambile, ukunuka iminti noma ukulalela imvula. Lokhu kuyisenzo sobuciko, hhayi ukwelashwa. Ukuhlola okumbalwa kokuphepha kwenza zikhululeke kubo bonke. Uma wena noma umuntu onakekelayo unenkinga yezempilo, njengobunzima bokugwinya, inkinga yesikhumba noma ukungezwa, khuluma nodokotela wakho noma nochwepheshe ogunyaziwe kuqala.

## Ubani lokhu okwabo?

Imisebenzi yezinzwa ifanele abantu abadala ezigabeni eziningi zokuphila. Isebenza kahle kumuntu othanda ukubamba izinto, kumuntu onamandla amancane ofuna umsebenzi oyinyumba, nakumuntu osichitha isikhathi esiningi esihlalweni noma embhedeni. Ingabelwana phakathi kwezizukulwane, njengengane nomuntu omdala ebamba ibhasikidi elifanayo lendwangu. Lezi yizincomo, hhayi ukuxilongwa.

## Yini ofunayo?

- Ibhasikidi noma ibhokisi lezinto, nesivalo uma ufuna ukuligcina lihlelekile
- Izinto ezinkulu nezivikelekile: izikwele zendwangu ethambile, ukhezo lwomthi, ilitshe elibushelelezi, isihlumela samakhambi
- Ukugcoba okungenaphunga noma okuthambile, uma isikhumba siphilile futhi umuntu engenayo ukungezwa
- Igumbi elithulile, nethelevishini evaliwe
- Ilaphu elifudumele, inkomishi yamanzi nesihlalo somuntu azohlala kuso

## Imibono yezinzwa, izinzwa ngayinye

**Ukuthinta**

- **Ukugcoba isandla.** Fudumeza amafutha amancane angenaphunga ezandleni zakho, bese uhamba kancane kusuka ezanyeni kuya kumahlumela eminwe. Ikhadi [ukugcoba isandla](/activity/give-a-hand-massage/) linezinyathelo.
- **Ibhasikidi lendwangu.** Izikwele ezinkulu zevelvethi, ikhodiroyi, i-fleece, isathini nowolintshi ukuze uzigcobe uzigoqe. Ikhadi [yenza ibhodi lokuthungwa](/activity/make-a-texture-board/) lithatha le mbono libe into ongayigcina.
- **Ukugoqa nokugudluza.** Amalaphu ahlanzekile okugeza noma amasaphu, ukuwagoqa, ukuwahlanganisa nokuwagoqa futhi. Ikhadi [goqa amathawuli ndawonye](/activity/fold-towels-together/) ngumsebenzi ozinzile.
- **Ilaphu elifudumele.** Ilaphu elifudumele, elimanzi lezandla ngosuku olubandayo. Hlola izinga lokushisa ngesihlakala sakho kuqala.

**Ukunuka**

- **Amakhambi amasha.** Hlikihla igqabi le-mint, le-rosemary noma le-basil phakathi kweminwe yakho, bese ulibamba eduze nekhala.
- **Amaphunga asekhishini.** Ikhofi elipheka, isinkwa esigazinga, noma iorenji elikhishwa esikhumbeni eseduze.
- **I-lavender eyomile.** Isikhwama esincane esihlanganiswe ngokuthungwa. Ikhadi [yenza isikhwama se-lavender](/activity/make-a-lavender-sachet/) likhombisa indlela.

**Umsindo**

- **Umculo ojwayelekile.** Izingoma ezijwayelekile ngevolumu ethambile. Bheka [umculo wokuthula nokuxhumana](/creative-calm/music-for-calm-and-connection/).
- **Imisindo yemvelo.** Imvula, amagagasi noma ukuhlabelela kwezinyoni, kudlalwa kancane.
- **Isisibambisi.** Ikhadi [yenza isisibambisi esivaliwe](/activity/make-a-sealed-shaker/) lenza okuphephile okungadlalwa ngakho ngomculo.

**Ukubona**

- **Ukubukela ewindini.** Isitsha sokondla izinyoni ngaphandle kwewindi, noma umbono wesitaladi. Ikhadi [bukela izinyoni ewindini](/activity/watch-birds-from-a-window/) linemibono.
- **Umbala nephethini.** Hlela izinkinobho noma izingcezu zendwangu ngombala usebenzisa ikhadi [hlela izinkinobho ngombala](/activity/sort-buttons-by-color/). Khetha izinkinobho ezinkulu kuphela.
- **Izimbali.** Ikhadi [hlela izimbali ndawonye](/activity/arrange-flowers-together/) yindlela ethambile yokuphatha, yokubukela nokunuka izimbali ezintsha.

## Yenza kanjani ibhokisi lezinzwa?

1. Khetha isihloko esihlobene nempilo yomuntu: ulwandle, ingadi, ikhishi, indawo yokusebenzela noma ukuthunga.
2. Khetha izinto ezinkulu, eziphephile ezinhlanu noma eziyisithupha, njengegobolondo elikhulu lolwandle, ukhezo lomthi, isikhafu sendwangu ethambile, isikhwama se-lavender esivaliwe noma ibhulokhi lomthi elibushelelezi.
3. Hlola yonke into ukuthola izingxenye ezincane, imiphetho ebukhali, izintambo ezikhululekile nanoma yini ephuka kalula.
4. Khipha into eyodwa ngesikhathi. Yinikeze, uyichaze, bese uvumela umuntu ayihlole.
5. Ngemva kwalokho gcina ibhokisi, bese uhlola izinto futhi ngaphambi kokusebenziswa okulandelayo.

## Ngomuntu omdala noma ohlala nesifo sokukhohlwa

Imisebenzi yezinzwa ibaluleke kakhulu ezigabeni zokugcina zesifo sokukhohlwa. I-[Alzheimer's Association](https://www.alz.org/help-support/caregiving/stages-behaviors/late-stage) ithi kulesi sigaba umhlaba uzwakala ikakhulu ngezinzwa, nokuthi ungabonisa inaki ngokuthinta, umsindo, ukubona, ukunambitha nephunga. I-[NHS](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/) iphakamisa ukuthi imisebenzi yezigaba zokugcina ngokuvamile igxila ezinzweni, njengokudlala umculo, ukuphatha izinto nokugcoba isandla.

Sondela, ubize igama lomuntu, bese ubuza noma utshele ngaphambi kokuthinta: "Nginamafutha athile. Ngabe ungathanda ukugcotshwa isandla?" Nikeza into eyodwa ngesikhathi. Qaphela ubuso obuthambile, izandla ezikhululekile noma intokozo. Ukuhoxa, ukuqamuka noma ukungakhululeki kusho ukuthi kufanele uyeke. Gcina isikhathi sibe cishe imizuzu emihlanu ethulile.

## Izinsiyo zokuphepha

Imisebenzi yezinzwa ithambile, kodwa kukhona izingozi ezibalulekile, ikakhulukazi kumuntu ongafaka izinto emlonyeni noma onenkinga yokugwinya.

| Ingozi | Yenzani |
| --- | --- |
| Ukuvinjwa | Sebenzisa izinto ezinkulu kuphela ezingenakugwinywa. Akukho izinkinobho, izinkanyezi, izinhlamvu noma izidlalo ezincane ezikhululekile ebhokisini. |
| Izinto ezibukeka njengokudla | Vala noma gcina kude amafutha, izinsipho, ushampu namafutha okugeza ngemva kokuwasebenzisa, ngoba angabukeka noma anuke njengokudla. Susa izithelo ezenziwe. |
| Ukungezwa | Hlola ukungezwa kukanati, i-latex, uboya, izitshalo noma amakhemikhali amaphunga ngaphambi kokuqala. |
| Amaphunga anamandla | Gwema amaphafumu anamandla namafutha abalulekile, ikakhulukazi uma kukhona i-asthma noma enye inkinga yokuphefumula. Amaphunga athambile, emvelo aphephile kakhulu. |
| Isikhumba | Hlola isikhumba esibuhlungu, esaphukile noma esibuthakathaka ngaphambi kokugcoba. Sebenzisa ingcindezi ethambile uyeke uma bebhekisisa ubuhlungu. |
| Izinga lokushisa | Hlola amalaphu afudumele neziphuzo ngesihlakala sakho kuqala. |
| Izinto ezibukhali noma eziyingozi | Akukho amathuluzi abukhali, ingilazi noma izinto ezingcolisayo zezandla. |

## I-aromatherapy isiza yini?

Mhlawumbe cha ngendlela ekalwayo. Ukubuyekezwa kwe-[Cochrane mayelana ne-aromatherapy yesifo sokukhohlwa](https://www.cochrane.org/evidence/CD003150_aromatherapy-dementia) kwathola izifundo ezingu-13 nabantu aba-708, bonke abahlala ezindaweni zokunakekela. Izifundo zazincane, imiphumela yazo yayingavumelani, futhi kayikhombisanga ubufakazi bokuzuza emiphumeleni ebhekiwe. Uma umuntu ejabulela iphunga elithambile nelijwayelekile, njengelavenda esuka ensimini, lokho kuyisizathu esihle sokwabelana ngalo. Akuyona ukwelashwa.

## Inketho yezinzwa ezimbalwa

Abanye abantu bathola ukuthola okuningi kukhathaza. Inguqulo yezinzwa ezimbalwa isebenzisa into eyodwa, ukukhanya okuthambile, ingubo efudumele kanye nokungabi nephunga. Hlalani ndawonye bese uvumela ukukhanya kuhambe odongeni, noma ubambe itshe elibushelelezi elilodwa. Gcina amazwi ephansi, bese unikeza ukuphumula noma nini ofisa. Uma umuntu ephenduka noma evala amehlo, lokho kuyisikhathi esiphelele.

## Uma kungasebenzi

Uma umuntu ezwa engakhululekile, yeka, faka into ngaphansi bese uhlala ngokuthula. Zama enye yezinzwa ngolunye usuku, noma ngesikhathi esihlukile sosuku. Abanye bathanda isikhathi sasekuseni, kanti abanye bathanda lapho indlu ithule kusihlwa. Ukuyeka kusenesikhathi kuyisiphetho esihle.

Ukuma kwe-[calm breathing](/games/calm-breathing/) kuyindlela ethambile yokuphetha isikhathi, nomphefumulo omunye ohamba kancane ngamunye, ngaphandle kokucindezela ukwenza okunye.
