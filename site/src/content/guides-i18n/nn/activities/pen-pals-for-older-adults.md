Eit brev er ein god felles aktivitet fordi det går i takt med den som skriv det. Det er ingen grunn til å svare fort. Eit kort kan lesast to gonger, visast til ein besøkande og oppbevarast i ei skuff. Denne sida tek for seg kven ein kan skrive til, korleis du finn eit program trygt, kva du kan sende når ord er vanskelege, og korleis ein hjelpar kan støtte skrivinga.

## Kvifor passar brev så godt?

Brev lar ein person vere med i sin eigen tid. Å velje papir og frimerke, skrive éi line og sende ho er små, ekte oppgåver med ein klar slutt. Alzheimer's Association si [aktivitetsguide](https://www.alz.org/help-support/caregiving/daily-care/activities) rår til å halde aktivitetar enkle og fokusere på prosessen heller enn resultatet, og eit brev passar godt til det rådet. Skrivinga treng ikkje vere lang for å bety noko.

## Kven kan vere brevven?

- **Eit barnebarn eller eit oldebarn,** særleg ein som lærer å skrive.
- **Ein gammal ven eller ein tidlegare kollega,** nokon personen allereie kjenner.
- **Ei klasse på ein lokal skule.** Spør læraren om klassa kan setje i gang ei brevutveksling.
- **Ein nabo,** som ville like eit kort notat over gata eller nedover gangen.
- **Eit trusfellesskap eller ein klubb** personen var med i tidlegare.

Brev til familien er den enklaste starten, fordi personen allereie veit kven som les dei.

## Korleis finn du eit program trygt?

Vel eit program som blir drive av ein organisasjon du kan kontrollere: ein skule, eit bibliotek, eit trusfellesskap, eit seniorsenter eller ein sjukeheim. Før du blir med, spør:

- Kven driv programmet, og kan du nå dei på telefon via eit oppgitt nummer?
- Blir dei som skriv brev sjekka eller følgde opp av tilsette?
- Finst det ein tilsett du kan kontakte om noko kjennest feil?

Bruk ikkje ein ukjend person som tek kontakt på nett og ber om adresse, bilete eller pengar. Vel eit program og hald deg til det. Organiserte program har folk du kan ringe.

## Kva er tryggleiksreglane?

- Del aldri bankopplysningar, kortnummer eller passord i eit brev.
- Send aldri pengar, gåvekort eller sjekkar til ein brevven, heller ikkje for ei historie som høyrest hastande ut.
- Hald heimeadressa privat. Bruk programmet si postboks eller organisasjonen si adresse, om det blir tilbode.
- Personen bestemmer kva som blir delt. Eit fornamn og ein by er ofte nok.
- Ta vare på brev ei stund, og fortel eit familiemedlem om alt som bekymrar deg.
- Meld frå om alt mistenkeleg til programmet. Har pengar vore med, kontakt banken din.

## Kva kan du sende når ord er vanskelege?

Eit brev treng ikkje mange ord. Prøv:

- **Ei teikning eller eit maleri,** med éi line under, til dømes «Dette er hagen vår i juni».
- **Eit pressa blad eller ei blomst.** Kortet [Press blad og blomar](/activity/press-leaves-and-flowers/) forklarar korleis du pressar dei i ei tung bok.
- **Eit bilete med éi line.** Vel eit bilete personen likar, og skriv bildeteksten saman.
- **Eit kort laga saman.** Kortet [Lag eit helsingskort](/activity/make-a-greeting-card/) dekkjer eit brettekort, nokre bilete og ei kort melding.
- **Ein liten collage av bilete.** Kortet [Lag ein minnekollasj](/activity/make-a-memory-collage/) lagar ei side som får plass i ei konvolutt.

Les opp alle brev du får, og lat personen diktere eit svar.

## Korleis kan ein hjelpar støtte skrivinga?

Sit ved sida av kvarandre, og still opne spørsmål: «Kva vil du fortelje?» Skriv ned nøyaktig dei orda personen seier, også om dei er korte eller blir gjenteke. Les brevet opp éin gong, og spør om noko skal endrast. [Første steg etter ein diagnose](/caregiving/after-dementia-diagnosis/) har meir om å stille opne spørsmål. Lat personen signere med sitt eige namn eller eit merke.

Somme familiar gjer brevet til ein fast del av ein [skriv eit brev saman](/activity/write-a-letter-together/)-økt ein vekedagsettermiddag. Telefon- og videosamtalar kan vere eit godt tillegg òg, og [guiden om telefon- og videosamtalar](/together/staying-connected-from-afar/) forklarar korleis du set dei opp. NHS si [side om aktivitetar](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/) listar opp videosamtalar blant aktivitetar mange kan halde fram med å ha glede av, og det er ei nyttig påminning om at eit brev ikkje er den einaste måten å halde kontakt på.
