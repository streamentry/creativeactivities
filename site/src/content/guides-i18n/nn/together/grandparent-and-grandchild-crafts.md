Besteforeldre og barnebarn leitar ofte etter noko å gjere saman som ikkje er ein skjerm. Eit handverk gir kvar av dei ei oppgåve. Besteforeldren blir behandla som ein vaksen med ei rolle og ei meining, og barnet får tillit til ekte arbeid. Denne sida set opp roller for kvar, ei kort liste med handverk som passar for ulike aldrar og grep, og tryggleikssteg for små born. For fleire parar av aktivitetar, sjå [samlesida for aktivitetar mellom besteforeldre og barnebarn](/grandparent-grandchild-activities/).

## Set rollene før du startar

Seie høgt kven som vel, kven som held, kven som skriv og kven som rydder. Eit barn som har ei oppgåve, held ut lenger. Ein besteforelder som blir spurd om meininga si, kjenner seg nyttig og ikkje styrt.

| Handverk | Besteforeldrens del | Barnets del |
| --- | --- | --- |
| [Familietre av hender](/activity/make-a-family-tree-of-hands/) | Vel stammen og seier kvart namn | Tegnar av hender med blyant og legg til alder |
| [Fotopostkort](/activity/make-a-photo-postcard/) | Seier meldinga og kven det er til | Vel biletet og skriv namnet |
| [Papirbåt](/activity/fold-a-paper-boat/) | Viser kvart brot, sakte | Fylgjer brota, og set båtane på vatnet |
| [Mal ein hagestein](/activity/paint-a-garden-stone/) | Vel fargane og mønsteret | Malar, med ein vaksen i nærleiken |
| [Vev papirstrimlar](/activity/weave-paper-strips/) | Held ramma og set mønsteret | Riv og trår strimlane |
| [Teikn gjentakande mønster](/activity/draw-repeating-patterns/) | Teiknar første rad | Held fram mønsteret |

Behandle besteforeldren som ein vaksen med ei rolle. Spør om meininga deira, og lat dei rette deg. Historiene deira er hovuddelen av besøket. Handverket er grunnen til å sitje saman.

## Handverk for ei blanda aldersgruppe

Fleire kort på dette nettstaden fungerer godt på tvers av generasjonar. Vel eitt som passar tida, rommet og alderen til barnet.

- [Mosaikk av rivne papir](/activity/tear-paper-mosaic/) bruker riven papir og lim. Barnet river, besteforeldren legg.
- [Lag eit helsingskort](/activity/make-a-greeting-card/) kan sendast til nokon annan i familien. Bruk ferdigklipte former til besteforeldren, om det hjelper.
- [Lag ei papirkjede](/activity/make-a-paper-chain-garland/) er godt for ei gruppe. Barnet river strimlane, og besteforeldren legg dei i løkker og set dei saman.
- [Bank ein rytme saman](/activity/tap-a-rhythm-together/) treng ingen materiale, og er ein god måte å starte eller avslutte eit besøk på.

## Tryggleik for små born

Hald den vaksne tett på og materiala enkle.

- **Under tre: ingen små delar.** Utelat perler, knappar, små steinar, frø, tørka bønner og alt som går gjennom ei papprull frå toalettpapir. Fleire kort på dette nettstaden listar små delar, så sjekk materiala før du startar.
- **Ingen ballongar** og ingen små bitar av skum eller plast i handverket.
- **Berre vaskbare, ugiftige materiale**, med ein vaksen som ser på all maling eller lim.
- **Ikkje varm lim eller varme verktøy.** Bruk limstift eller vaskbar skolelim.
- **Saks berre med ein vaksen**, og berre for eldre born som har brukt dei før. Å rive papir er eit godt alternativ.
- **Ingen mat** som handverksmateriale. Hald eteleg mat til eting, og borte frå bordet der dykk jobbar.
- **Hald malarvatnet i ei kopp,** ikkje i eit fat, og tøm det når barnet er ferdig.
- **Vask hendene** etter maling, lim eller jord.

Ikkje ta bilete av born for å dele dei, og ikkje legg ut namn, alder eller skule til eit barn på nettet utan at foreldra har sagt ja. Hald familietreet, oppskriftsboka og songboka innanfor familien.

## Tilpassing for ein besteforelder med avgrensa grep eller syn

- Bruk tjukke fargestiftar, tjukke markørar og store pensler med polstra handtak.
- Tape papiret til bordet, så det ikkje glir.
- Bruk ferdigklipte former, eller ferdigriven papir, slik at besteforeldren kan plassere dei i staden for å klippe.
- Bruk høg kontrast, til dømes svart markør på kvitt papir, og stor skrift på alle etikettar.
- Sit ved sida av kvarandre, så både barnet og besteforeldren kan sjå arbeidet.

[Rettleiinga om kunst og musikk](https://www.alz.org/help-support/caregiving/daily-care/art-music) frå Alzheimer's Association peikar på at kunstprosjekt kan gi ei kjensle av meistring og meining. Ho rår òg til å bruke trygge materiale og unngå giftige stoffar og skarpe verktøy. Desse reglane passar godt for eit bord med blanda aldrar.

## Om besteforeldren har endringar i hukommelsen

Bruk enkle, ærlege ord før besøket. Seie kva som er annleis og kva som er det same: Bestefar kan gløyme eit namn eller fortelje same historia igjen, og han likar framleis selskap. Be barnet om ein liten del av historia, i staden for ein test. Inviter dei til å spørje: «Korleis var det då du var liten?» Unngå å spørje om besteforeldren hugsar noko.

Om barnet spør om noko du ikkje kan svare på, seie det. «Eg veit ikkje, men vi kan spørje bestemor når ho er klar.» Ærlege svar hjelper born å kjenne seg trygge.

## Viss det ikkje fungerer

Kort ned handverket, byt oppgåve, eller stopp. Eit barn som har mist interessa treng ikkje ferdigstille. Legg materiala i ein boks og kom attende ein annan dag. Om besteforeldren er trøytt, gjer barnets del større, og lat besteforeldren sjå på og kommentere.

## Tips for ei god økt

- Legg fram alle materiala før barnet kjem.
- Vel eit bord med godt lys og ein duk som beskyttar det.
- Start med det enklaste steget, så barnet kjenner seg vellykka tidleg.
- Avslutt med noko å ta vare på, vise fram eller gi bort.
- Avslutt med eit mellommål og ein tur, eller ei roleg forteljing.
