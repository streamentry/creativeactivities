Mange kjenner att det same mønsteret. Formiddagane kjennest ganske stabile, men etter kvart som ettermiddagen går, blir personen trøytt, rastlaus eller lett opprørt. Denne sida gir ein mild dagsrytme og roelege aktivitetar for seint på ettermiddagen. Det er ein guide om kreative aktivitetar, ikkje terapi. Om du eller personen du tek vare på har eit helseproblem, snakk med eigen lege eller ein autorisert fagperson, særleg om endringa er ny.

## Korleis ser ein mild dag ut?

Tidene er berre døme. Flytt heile dagen tidlegare eller seinare for å passe personens eigen rytme, og hald rekkjefølgja fast heller enn klokkeslettet.

| Tid | Kva skjer | På ein tyngre dag |
| --- | --- | --- |
| Morgon | Vakne, vaske seg, kle på seg og eta frukost i same rekkjefølgje kvar dag | Ei ny skjorte og ein enkel frukost er nok |
| Seint på formiddagen | Hovudaktiviteten: ein kort tur, baking eller ei oppgåve med ein tydeleg slutt | Ein kortare versjon, eller sjå på at du gjer det |
| Midt på dagen | Lunsj, deretter ei roleg pause | Hopp over alle gjeremål |
| Tidleg på ettermiddagen | Kvil ved behov, i ein favorittstol | Same, med ein varm drikke |
| Midt til seint på ettermiddagen | Roelege, kjende aktivitetar, ein matbit og ein drikke, utan koffein | Ein matbit og roleg selskap |
| Før skumring | Dra for gardinane og tenn lys inne | Tenn lys i rommet før skuggane kjem |
| Kveld | Eit lettare måltid, mjuk musikk, lite støy | Trøyst og ro først |
| Leggetid | Dei same stega kvar kveld, med dempa lys | Gjer alt kortare |

## Korleis byggjer du ein rytme som passar?

Ta utgangspunkt i korleis personen alltid har levd, heller enn i eit skjema. Tenk på kva personen liker og ikkje liker, og korleis dagane vart brukte tidlegare. Ein tidleg oppvakna som alltid gjekk tur før frukost, kan ønskje å halde på den vanen. Eit kveldsmenneske har kanskje aldri hatt glede av ein tidleg start.

- **Set krevjande ting tidlegare.** Dusjing, turar og oppgåver som krev innsats, blir lagde til morgonen eller tidleg på ettermiddagen, når mange er meir opplagte.
- **Hald vekking og leggetid faste.** Alzheimer's Association peikar på at faste tider for vekking og leggetid kan hjelpe ved søvnproblem og rastløyse seint på dagen.
- **Set av rom til å puste.** Ikkje fyll kvart minutt. Kvile er ein del av dagen.
- **Lat rom for det uventa.** Ein besøkjande, ein solskinsperiode eller ein favorittsong kan endre planen, og det er greitt.

## Korleis kan du verne ettermiddagen?

- **Dagslys.** Set av tid ute eller ved eit solrikt vindauge kvar dag.
- **Mild bevegelse.** Ein tur eller nokre minutt med aktivitet kvar dag, men ikkje for mykje oppå ein travel plan.
- **Drikke.** Unngå koffein og alkohol seinare på dagen. Tilby ein varm drikke utan koffein i staden.
- **Lurar.** Avgrens lange lurar og dorming seint på dagen, særleg om søvnen om natta er vanskeleg.
- **Lys og lyd.** Dra for gardinane og tenn lys før skumring. Skru ned fjernsyn, radio og anna støy i huset.
- **Kontroll av komfort.** Sjekk etter smerte, hunger, tørst, full blære, tretthet, hudirritasjon eller eit rom som er for varmt eller kaldt. Alt dette kan sjå ut som rastløyse.

## Roelege aktivitetar seint på ettermiddagen

Vel aktivitetar som er kjende, utan hast og enkle å stoppe. Unngå nye spel, travle turar og alt som krev mykje konsentrasjon. Set desse av til morgonen.

1. **Brett handklede saman.** Handklede er lette å halde i, og oppgåva har ein tydeleg slutt. Kortet [brett handklede saman](/activity/fold-towels-together/) har steg.
2. **Spel ein favorittliste.** Kjende songar på lågt volum. Å nynne med tel òg. Kortet [lag ein spelelist saman](/activity/make-a-playlist-together/) er ein god stad å starte.
3. **Sjå på bilete.** Eit album, eller nokre få bilete, utan quiz. Det er nok berre å sjå. Kortet [sjå gjennom eit fotoalbum](/activity/look-through-a-photo-album/) viser korleis.
4. **Slå ein rytme.** Klapp på bordet, eller bruk ein shaker i takt med musikken. Sjå [slå ein rytme saman](/activity/tap-a-rhythm-together/).
5. **Sorter etter farge.** Å sortere knappar eller sokkar er ei oppgåve som krev stø hand. Kortet [sorter knappar etter farge](/activity/sort-buttons-by-color/) har steg.
6. **Ta ein kort tur.** Rundt hagen, kvartalet eller ein gang, før det blir mørkt.
7. **Del ein varm drikke.** Noko enkelt, ved bordet saman.
8. **Sjå på fuglar.** Kortet [sjå på fuglar frå eit vindauge](/activity/watch-birds-from-a-window/) viser korleis du kan gjere det til ei felles stund.
9. **Spel eit mildt paringsspel.** [Bildepar](/games/picture-pairs/) med bileta synlege er lett å starte og lett å stoppe.
10. **Ta ein pause og pust.** [Roleg pusting](/games/calm-breathing/) er ei langsam pause som du startar og stoppar sjølv.

## For ein som lever med demens

Seint på ettermiddagen blir mange som lever med demens meir rastlause eller forvirra. Somme familiar kallar dette sundowning. Hald deg roleg og snakk lågt. Bruk korte, trygge ord, og tilby ein matbit, ein drikke, litt musikk eller ein kort tur. Unngå å krangle med personen, rette vedkommande eller presse vedkommande inn i eit hjørne. Start ikkje ein ny eller krevjande aktivitet seint på dagen. Hald dei same kveldsstega kvar kveld, slik at rutinen i seg sjølv blir ei kjelde til tryggleik.

Viss personen blir aggressiv, hald trygg avstand til åtferda har roa seg. Viss nokon er i fare, ring det lokale naudnummeret der du bur. Guiden vår om [når dei seier nei](/caregiving/when-they-say-no/) har meir om korleis du kan svare mildt når ein person seier nei.

## Tryggleiksmerknader

- Ikkje hald personen fast, og ikkje sperr ei dør for å stoppe vedkommande frå å bevege seg. Gå heller saman med personen, på ein trygg stad.
- Oppbevar medisin på vanleg stad, og gi berre det forskrivaren har sett. Spør legen om kva tid på dagen som er best for kvar medisin, slik Alzheimer's Association tilrår.
- Start, stopp eller endre ingen søvnhjelp, kosttilskot eller medisin utan medisinsk råd.
- Hald varme drikkar unna bordkanten, og hald gangvegane frie i dårleg lys.

## Viss det ikkje fungerer

Før ein kort logg i ei veke eller to. Noter kva tid rastløysa starta, kva som skjedde den siste timen før, lurar, måltid, besøkjande, støy og lys. Ta loggen med til legen. Mønster kjem ofte fram i loggen, mønster som er vanskelege å sjå frå dag til dag.

Viss den same kvelden er vanskeleg kvar dag, prøv ein annan aktivitet, eit anna rom, eller ein seinare start på den roelege perioden. Viss du blir utsliten av kveldane, sjå på sida om [egenomsorg for pårørande](/creative-calm/creative-self-care-for-caregivers/) for korte pausar og støtte.

Å stoppe tidleg er eit godt resultat. Det same gjeld å sitje saman utan å gjere noko i det heile.
