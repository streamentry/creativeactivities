Ein Regentag drinnen kann lang werden. Ein paar Bastelideen aus Dingen, die ohnehin im Haus sind, füllen einen Nachmittag, und das Kind kann sie unterwegs verändern. Dieser Leitfaden richtet sich an Eltern, Großeltern und Betreuende von Kindern ab etwa 3 Jahren. Er enthält vier Bastelideen, jede mit einer Liste von Haushaltsmaterial, einigen Schritten und einfachen Varianten.

Alle vier Ideen nutzen Material, das in den meisten Haushalten vorhanden ist: Kartonrollen von Küchenrolle und Toilettenpapier, Eierkartons, Papptellern und altes Zeitungspapier. Dazu brauchen Sie vielleicht etwas Klebeband, ungiftigen Kleber und abwaschbare Farbe.

## Für wen sich das eignet

Diese Ideen passen zu Kindern, die gern mit den Händen arbeiten, etwas verzieren oder mit Puppen und Figuren Geschichten erzählen. Sie passen zu Kindern, die eine klare Abfolge von Schritten mögen, und zu Kindern, die es genießen, einen Plan zu ändern. Jüngere Kinder ab etwa 3 Jahren brauchen meist Hilfe mit Schere und Kleber. Ältere Kinder können die meisten Schritte oft allein machen, während ein Erwachsener in der Nähe bei den schwierigeren Teilen hilft.

## Sicherheit zuerst

- **Erwachsene in der Nähe.** Bleiben Sie in der Nähe, wenn Schere, Kleber, Klebeband oder Farbe benutzt werden.
- **Stumpfe Scheren.** Verwenden Sie für Kinder unter etwa 6 Jahren stumpfe Scheren, und lassen Sie einen Erwachsenen jede Form ausschneiden, die eine scharfe Klinge braucht.
- **Ungiftiges Material.** Achten Sie auf ein klares Etikett „ungiftig“ bei Farbe, Stiften und Kleber. Das Art and Creative Materials Institute vergibt sein Siegel „Approved Product“ an geprüftes Bastelmaterial.
- **Kleine Teile.** Kinder unter 3 Jahren sollten keine kleinen Teile haben, zum Beispiel ausgeschnittene Eierkartonmulden, Flaschenverschlüsse, Knöpfe, kleine Klebebandrollen oder Perlen. Der Choking-Leitfaden von Nemours KidsHealth nennt Bastelmaterial und kleine Spielzeugteile unter den häufigen Erstickungsgefahren. Entfernen Sie alle kleinen Teile vom Tisch, wenn die Bastelei fertig ist.
- **Schnüre.** Halten Sie Faden, Wolle und Schnur für Kinder unter 3 Jahren fern, und binden Sie Schnur niemals um den Hals eines Kindes.
- **Latex.** Verwenden Sie keine Latexluftballons. Wenn ein Familienmitglied allergisch auf Latex reagiert, prüfen Sie, ob Gummibänder und Radiergummis latexfrei sind. Die American Academy of Allergy, Asthma and Immunology weist darauf hin, dass Naturkautschuklatex häufig in Luftballons, Gummibändern und Radiergummis enthalten ist.
- **Lebensmittel und Farbstoffe.** Manche Familien verzichten auf Lebensmittelfarbstoffe. Verwenden Sie abwaschbare Farbe oder farbiges Papier statt Lebensmittelfarbe.

## Puppen aus Kartonrollen

**Das brauchen Sie:** drei oder vier Kartonrollen von Küchenrolle oder Toilettenpapier; Papier oder Karton; Buntstifte oder abwaschbare Filzstifte; Klebeband oder Kleber; eine Schere für den Erwachsenen; Wackelaugen nur, wenn das Kind 5 Jahre oder älter ist, da sie ein Kleinteil sind.

**Schritte:**

1. Wählen Sie eine Rolle als Körper. Verzieren Sie sie mit Buntstiften oder Farbe und lassen Sie sie trocknen.
2. Zeichnen Sie ein Gesicht auf ein Blatt Papier. Ein Erwachsener kann das Gesicht ausschneiden, oder das Kind schneidet es mit einer stumpfen Schere aus.
3. Kleben oder kleben Sie das Gesicht mit Klebeband an ein Ende der Rolle.
4. Fügen Sie Arme aus gefaltetem Papier hinzu, die mit Klebeband an den Seiten der Rolle befestigt werden.
5. Stecken Sie Ihre Hand in die Rolle und lassen Sie die Puppe sprechen. Lassen Sie das Kind dasselbe tun.

**Einfachere Variante:** Bitten Sie einen Erwachsenen, Rolle und Gesicht vorab zuzuschneiden. Lassen Sie das Kind mit großen Aufklebern verzieren, die sich leicht abziehen lassen.

**Ruhigere Variante:** Verwenden Sie nur eine Farbe und machen Sie eine einzige Puppe. Eine ruhige Puppenvorstellung mit einer Figur kann genauso erfüllend sein wie eine längere.

## Raupen aus Eierkartons

**Das brauchen Sie:** einen Eierkarton mit mindestens sechs Mulden; abwaschbare Farbe oder Filzstifte; Pfeifenreiniger für die Fühler, von einem Erwachsenen in kurze Stücke geschnitten; Kleber oder Klebeband.

**Schritte:**

1. Ein Erwachsener schneidet den Karton in Streifen mit drei oder vier Mulden. Achten Sie darauf, dass die Schnittkanten glatt sind.
2. Lassen Sie das Kind jede Mulde bemalen oder ausmalen. Es darf die Farben selbst wählen.
3. Wenn die Farbe trocken ist, kleben Sie die Mulden in einer Reihe auf, wobei die Öffnungen nach oben zeigen.
4. Setzen Sie der ersten Mulde ein Gesicht auf und befestigen Sie vorne die Pfeifenreiniger als Fühler. Halten Sie die Pfeifenreiniger kurz und mit stumpfen Enden.
5. Stellen Sie die Raupe auf eine Fensterbank, und machen Sie eine zweite, wenn das Kind es möchte.

**Einfachere Variante:** Verwenden Sie einen Karton, der bereits in Streifen geschnitten ist, und lassen Sie das Kind mit einem Schwamm oder Pinsel verzieren.

**Ruhigere Variante:** Verwenden Sie für die ganze Raupe nur eine Farbe. Lassen Sie die Fühler weg.

## Masken aus Papptellern

**Das brauchen Sie:** Papptellern; eine Schere für den Erwachsenen, um die Augenlöcher zu schneiden; Schnur oder Gummiband für die Rückseite, von einem Erwachsenen zugeschnitten; Buntstifte, Filzstifte oder abwaschbare Farbe; Papierreste.

**Schritte:**

1. Ein Erwachsener schneidet zwei Augenlöcher in den Teller, in der passenden Höhe für das Kind. Die Löcher sollten groß genug sein, dass man hindurchsehen kann.
2. Lassen Sie das Kind den Teller verzieren. Bieten Sie Farbe, Filzstifte und Papierreste für Ohren, Haare oder eine Nase an.
3. Lassen Sie die Farbe vollständig trocknen, bevor die Maske getragen wird.
4. Ein Erwachsener bindet die Schnur oder das Gummiband hinten fest, aber so locker, dass man die Maske leicht auf- und absetzen kann.
5. Lassen Sie das Kind die Maske für eine kurze Zeit tragen, um ein Tier oder eine Figur zu spielen.

**Einfachere Variante:** Verwenden Sie einen Teller, bei dem die Augenlöcher schon ausgeschnitten sind. Bieten Sie Aufkleber oder Stempel statt Farbe an.

**Ruhigere Variante:** Machen Sie die Maske ohne Ohren, Haare oder zusätzliche Teile. Lassen Sie den Teller schlicht und ruhig.

**Sicherheitshinweis:** Eine Maske kann die Sicht erschweren. Bleiben Sie deshalb in der Nähe des Kindes und beenden Sie das Spiel, wenn es nicht mehr klar sehen kann. Lassen Sie ein Kind mit Maske nie allein.

## Collage aus Zeitungspapier

**Das brauchen Sie:** altes Zeitungs- oder Zeitschriftenpapier; ein Blatt Karton; einen Klebestift oder Klebeband; eine Schere für den Erwachsenen oder zum Reißen mit der Hand.

**Schritte:**

1. Reißen Sie die Zeitung in Streifen und Stücke. Das Kind darf so viel reißen, wie es möchte.
2. Zeichnen Sie einen einfachen Umriss auf den Karton, etwa ein Haus, ein Boot oder eine Form.
3. Kleben Sie die Papierstücke innerhalb des Umrisses fest, jeweils eines nach dem anderen.
4. Lassen Sie das Kind entscheiden, wohin jedes Stück kommt. Überlappungen sind in Ordnung.
5. Lassen Sie die Collage flach trocknen und zeigen Sie sie jemandem aus der Familie.

**Einfachere Variante:** Reißen Sie das Papier vorab und verwenden Sie einen dicken Klebestift, damit die Stücke leicht haften.

**Ruhigere Variante:** Verwenden Sie nur eine Papierfarbe, etwa Blau, und gestalten Sie eine einzige Form.

## Gemeinsam mit einem Großelternteil basteln

Ein Großelternteil kann zusammen mit dem Kind eine Puppe oder Maske basteln. Jeder kann sein fertiges Stück zeigen, und die beiden können sich durch die Puppen unterhalten. Ein Großelternteil, dem es schwerfällt, auf dem Boden zu sitzen, kann am Tisch mit dem Kind arbeiten. Weitere Ideen zum gemeinsamen Ausprobieren finden Sie im Abschnitt [gemeinsame Ideen](/together/).

Wenn Ihre Familie weit entfernt lebt, können Sie dieselbe Bastelei an beiden Orten machen und sich die fertigen Stücke bei einem Anruf zeigen. Für eine längere Idee gibt [Eine Papierkette basteln](/activity/make-a-paper-chain-garland/) ein gemeinsames Ergebnis, das in jedem Zuhause aufgehängt werden kann.

## Wenn es nicht klappt

- **Das Kind möchte den Plan ändern.** Lassen Sie es. Eine Puppe mit einem zusätzlichen Arm kann besser sein als die, die Sie geplant hatten.
- **Das Kind verliert nach einem Teil das Interesse.** Hören Sie dort auf. Lassen Sie die Teile trocknen und machen Sie an einem anderen Tag weiter.
- **Der Kleber ist überall.** Nehmen Sie Klebeband oder stellen Sie den Kleber auf ein Tablett, damit das Kind Teile direkt auf den Kleber drücken kann.
- **Das Kind ärgert sich über das Schneiden.** Lassen Sie einen Erwachsenen schneiden und das Kind verzieren, reißen und kleben.

Wenn Sie eine Frage zur Gesundheit oder zu Allergien eines Kindes haben, fragen Sie die behandelnde Ärztin oder den behandelnden Arzt Ihres Kindes.
