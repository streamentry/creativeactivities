Manche Kinder mögen am Ende eines vollen Tages ruhige, langsame Dinge, oder wenn sie einfach etwas Sanftes möchten. Dieser Leitfaden bietet fünf Ideen, für die kaum mehr nötig ist als Papier, Buntstifte, etwas Knetmasse und ein ruhiger Raum. Jede davon ist eine Wahl. Das Kind kann sie annehmen, verändern oder ablehnen, und Sie hören auf, wenn es aufhört.

Dieser Leitfaden richtet sich an Eltern, Großeltern und Betreuungspersonen von Kindern ab etwa 3 Jahren. Jüngere Kinder können mit Hilfe einer erwachsenen Person mitmachen, aber halten Sie die Aktivitäten kurz und in der Nähe.

## Für wen das passt

Diese Ideen passen zu Kindern, die gern malen, zeichnen, Papier reißen oder Knete drücken, und zu Kindern, die eine vorhersehbare, ruhige Beschäftigung mögen. Sie können gut passen, wenn ein Kind müde ist, wenn es vorher laut gespielt hat oder wenn es in Ihrer Nähe sein möchte, ohne viel zu reden. Sie kennen Ihr Kind am besten. Bieten Sie jeweils eine Idee an und achten Sie darauf, was es wählt.

Diese Ideen sind keine Behandlungen und versprechen kein bestimmtes Ergebnis. Sie sind ganz gewöhnliche Wege, gemeinsam eine ruhige Zeit zu verbringen.

## Grundregeln

- **Anbieten, nicht vorschreiben.** Sagen Sie „Möchtest du ein bisschen malen?“ statt „Du musst dich jetzt beruhigen.“
- **Das Kind darf Nein sagen.** Lehnt es ab, bieten Sie etwas anderes an oder heben Sie es für ein anderes Mal auf.
- **Hören Sie auf, wenn das Kind aufhört.** Machen Sie nicht weiter, nur weil Sie eine längere Zeit geplant hatten.
- **Nie als Strafe einsetzen.** Ruhige Aktivitäten sollen etwas sein, das das Kind genießen kann, nichts, das es verliert.
- **Erwachsene in der Nähe.** Bleiben Sie in Reichweite bei jeder Aktivität mit Wasser, Knete, Strohhalmen oder kleinen Teilen.
- **Ungiftig und abwaschbar.** Achten Sie auf ein klares Kennzeichen „ungiftig“ bei Buntstiften, Farben und Knete. Das Art and Creative Materials Institute vergibt ein Siegel „Approved Product“ für geprüfte Künstlermaterialien.

## Malen mit leiser Musik

**Was Sie brauchen:** ein paar große Blätter Papier oder eine Malvorlage; Buntstifte oder Farbstifte; ein ruhiges Lied oder sanfte instrumentale Musik in leiser Lautstärke.

**Schritte:**

1. Wählen Sie ein Bild oder ein leeres Blatt. Lassen Sie das Kind die Farben aussuchen.
2. Spielen Sie ein ruhiges Musikstück leise ab, oder sitzen Sie ohne Musik da.
3. Malen Sie neben dem Kind, und malen Sie gern Ihr eigenes Bild.
4. Stellen Sie eine offene Frage, zum Beispiel „Welche Farbe hat die Musik?“, und warten Sie.
5. Hören Sie auf, wenn das Kind aufhört, und räumen Sie die Stifte gemeinsam zurück in die Schachtel.

**Einfachere Variante:** Nehmen Sie eine große, einfache Vorlage mit dicken Linien. Bieten Sie drei Stifte statt einer ganzen Schachtel an.

**Ruhigere Variante:** Nehmen Sie eine Farbe und ein leeres Blatt. Lassen Sie das Kind zeichnen, was es möchte, oder die Seite langsam mit einer einzigen Form füllen.

## Papier langsam reißen

**Was Sie brauchen:** ein Blatt buntes Seidenpapier oder dünnes Bastelpapier; eine Schale oder ein Tablett für die Stücke; ein Blatt Karton und einen Klebestift, falls das Kind ein Bild machen möchte.

**Schritte:**

1. Reißen Sie das Papier in lange, langsame Streifen, einen nach dem anderen. Lassen Sie das Kind das Tempo bestimmen.
2. Sortieren Sie die Streifen nach Farben in die Schale, oder lassen Sie sie gemischt.
3. Möchte das Kind ein Bild machen, kleben Sie die Streifen in einem beliebigen Muster auf den Karton.
4. Hören Sie auf, wenn das Kind aufhört. Die Streifen können für ein andermal aufgehoben werden.

**Einfachere Variante:** Reißen Sie das Papier vorher in Streifen, und lassen Sie das Kind sie aufkleben.

**Ruhigere Variante:** Reißen Sie nur eine Farbe, und reißen Sie langsam mit beiden Händen.

## Malen zu Musik

**Was Sie brauchen:** Papier; Buntstifte oder Filzstifte; ein Musikstück mit klarem Takt oder einer langsamen, sanften Melodie.

**Schritte:**

1. Spielen Sie die Musik leise ab.
2. Bitten Sie das Kind zu malen, während es zuhört. Malen Sie selbst mit, oder sitzen Sie still dabei.
3. Fragen Sie: „Geht die Musik nach oben oder nach unten?“ Lassen Sie das Kind mit einer Linie antworten.
4. Hören Sie nach ein oder zwei Stücken auf, oder wenn das Kind bereit ist.

Eine vollständige Anleitung finden Sie unter [Zu Musik malen](/activity/draw-to-music/).

**Einfachere Variante:** Malen Sie alle paar Sekunden Musik eine Linie, und lassen Sie das Kind die Lücken füllen.

**Ruhigere Variante:** Spielen Sie leisere Musik oder gar keine, und malen Sie, indem Sie auf das Papier schauen.

## Knetmasse

Knetmasse ist für viele Kinder eine gute ruhige Beschäftigung, braucht aber Sorgfalt. Selbstgemachte Knete besteht meist aus Mehl, Salz und Wasser, und Mehl enthält Weizen. Weizen gehört zu den häufigen Lebensmittelallergenen, die von Food Allergy Research and Education aufgeführt werden. Fragen Sie die Familie, bevor Sie Knete machen oder verwenden, und kaufen Sie handelsübliche Knete mit der Kennzeichnung „ungiftig“, wenn Sie das bevorzugen.

**Was Sie brauchen:** eine kleine Menge Knetmasse auf einem Tablett oder einer Matte; ein Nudelholz oder ein stumpfes Werkzeug; ein paar sichere Formen, zum Beispiel einen Plastikausstecher.

**Schritte:**

1. Legen Sie die Knete auf das Tablett. Zeigen Sie dem Kind, wie man sie drückt, rollt und flach macht.
2. Lassen Sie es eine Form in die Knete drücken oder eine Kugel formen.
3. Fragen Sie, welche Form es machen möchte, und lassen Sie es wählen.
4. Wenn das Kind fertig ist, packen Sie die Knete in einen luftdichten Behälter.

**Sicherheitshinweise:** Knetmasse ist nicht zum Essen oder Lutschen gedacht. Geben Sie sie keinem Kind unter 3 Jahren, das sie in den Mund stecken könnte. Halten Sie kleine Formen und Werkzeuge für Kinder unter 3 Jahren außer Reichweite, und waschen Sie sich nach dem Spielen die Hände.

**Einfachere Variante:** Nehmen Sie ein größeres Stück Knete und einen großen Ausstecher. Lassen Sie das Kind die Knete mit der Handfläche drücken.

**Ruhigere Variante:** Behalten Sie die Knete in einer Farbe. Sitzen Sie ruhig dabei und drücken Sie Ihr eigenes Stück.

## Sanftes Atmen mit Wasserblasen

Mit einem Strohhalm in einem Becher Wasser Blasen zu erzeugen, ist eine spielerische Aktivität. Dafür muss jederzeit eine erwachsene Person in der Nähe sein.

**Was Sie brauchen:** einen durchsichtigen Becher, halb mit Wasser gefüllt; einen Plastikstrohhalm; eine erwachsene Person, die neben dem Kind sitzt.

**Schritte:**

1. Füllen Sie den Becher mit einer kleinen Menge Wasser. Stellen Sie den Strohhalm in den Becher, sodass das Ende knapp unter der Oberfläche ist.
2. Zeigen Sie dem Kind, wie es sanft durch den Strohhalm pustet, um kleine Blasen zu machen.
3. Lassen Sie es ein paar Mal probieren, und machen Sie dann eine Pause. Warten Sie zwischen den Versuchen.
4. Leeren Sie den Becher, wenn die Aktivität vorbei ist, und halten Sie den Strohhalm, wenn er nicht benutzt wird, vom Gesicht des Kindes fern.

**Sicherheitshinweise:** Bleiben Sie während der ganzen Aktivität beim Kind. Verwenden Sie nur einen kurzen Plastikstrohhalm mit einem Becher Wasser. Lassen Sie das Kind nicht aus dem Becher trinken, und lassen Sie es nicht ohne Aufsicht mit dem Strohhalm im Mund blasen.

**Einfachere Variante:** Lassen Sie eine erwachsene Person den Becher halten, während das Kind bläst. Verzichten Sie auf den Strohhalm und lassen Sie das Kind sanft Blasen auf einen Teller pusten.

**Ruhigere Variante:** Bieten Sie ein oder zwei Atemzüge an, und hören Sie dann auf. Eine einzige Blase kann genug sein.

## Gemeinsam mit den Großeltern

Großeltern können leise vorlesen, während das Kind malt, oder am anderen Ende des Tisches zeichnen. Ein Großelternteil, der weit entfernt wohnt, kann während eines Anrufs dasselbe Bild malen, während das Kind seine Seite in die Kamera hält. Weitere Ideen für gemeinsame Zeit finden Sie im Bereich [gemeinsame Ideen](/together/).

## Wenn es nicht klappt

- **Das Kind lehnt ab.** Akzeptieren Sie das. Bieten Sie eine andere Idee zu einem anderen Zeitpunkt an, oder sitzen Sie einfach zusammen.
- **Das Kind wird aufgebrachter.** Beenden Sie die Aktivität und geben Sie ihm Raum. Bleiben Sie in der Nähe und sprechen Sie ruhig. Tritt das häufig auf, sprechen Sie mit der Ärztin oder dem Arzt Ihres Kindes.
- **Das Kind steckt Knete oder Buntstifte in den Mund.** Nehmen Sie den Gegenstand weg und hören Sie auf. Geben Sie einen sicheren Gegenstand zum Festhalten.
- **Das Kind möchte weitermachen.** Hören Sie auf, wenn Sie vorhatten aufzuhören, und sagen Sie, was als Nächstes passiert. Lassen Sie die Materialien für ein andermal liegen.

Wenn Sie eine Frage zur Gesundheit eines Kindes haben, fragen Sie die Ärztin oder den Arzt Ihres Kindes. Diese Aktivitäten ersetzen dieses Gespräch nicht.
