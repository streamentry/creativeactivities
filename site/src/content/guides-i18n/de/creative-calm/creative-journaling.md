Ein kreatives Journal ist ein Ort, um kleine Dinge auf Papier festzuhalten: eine Farbe, die Ihnen aufgefallen ist, ein Blatt, eine Zeile aus einem Lied, eine Liste, wie das Wetter war. Es ist eine kreative Tätigkeit, keine Therapie. Es verlangt nicht, dass Sie sich erklären. Wenn Sie oder die Person, die Sie begleiten, ein gesundheitliches Anliegen haben, sprechen Sie mit Ihrer Ärztin oder Ihrem Arzt oder einer anderen zugelassenen Fachperson.

## Für wen ist das gedacht?

Kreatives Journaling eignet sich für Erwachsene, die gern mit den Händen etwas herstellen und eine stetige, private Gewohnheit möchten. Es passt zu Menschen, denen Schreiben schwerfällt, die aber Bilder mögen, und zu denen, die eine kurze Liste einer langen Seite vorziehen. Es kann auch eine gemeinsame Tätigkeit sein, etwa ein Familien-Collagebuch, zu dem mehrere Personen beitragen. Das sind Vorschläge. Nehmen Sie, was sich für Sie gut anfühlt.

## Was benötigen Sie?

- Ein Notizbuch mit glatten oder dickeren Seiten oder lose Blätter in einer Mappe
- Klebestift, Schere mit abgerundeten Spitzen und Kreppband
- Alte Zeitschriften, Kataloge, Geschenkpapier, Stoffreste oder Fotoabzüge, die Sie selbst auswählen
- Stifte, Bleistifte, Buntstifte oder Filzstifte
- Getrocknete Blätter, Ticketreste oder andere flache Dinge, die Sie schon haben

## Drei einfache Arten von Journal

**Das Collage-Journal.** Jede Seite hat ein Thema, etwa weiche Dinge, blaue Dinge oder Dinge, die man hören kann. Reißen oder schneiden Sie Formen aus Papier, das Sie schon besitzen, und ordnen Sie sie an. Kleben Sie sie fest, wenn Ihnen das Layout gefällt. Die Karte [Eine Farbcollage gestalten](/activity/make-a-color-collage/) enthält Schritte zur Vorbereitung.

**Das Zeichenjournal.** Zeichnen Sie jeden Tag einen Gegenstand, mit Bleistift oder Stift, mit wenigen Linien und etwas Farbe. Die Zeichnung muss nicht fertig sein. Die Karte [Skizzieren, was auf dem Tisch liegt](/activity/sketch-what-is-on-the-table/) passt hier gut.

**Das Listen- und Skizzenjournal.** Schreiben Sie eine kurze Liste, etwa drei Geräusche, die Sie heute gehört haben, oder skizzieren Sie einen einzelnen Blick aus dem Fenster. Eine oder zwei Zeilen reichen.

## Impulse ohne Gefühlsfragen

Wählen Sie beim Öffnen des Journals einen Impuls und heben Sie die übrigen für einen anderen Tag auf.

1. Zeichnen oder notieren Sie das Erste, was Sie beim Aufwachen sehen.
2. Kleben Sie fünf Papier- oder Stoffstücke mit unterschiedlicher Oberfläche auf und beschriften Sie sie nur nach dem Tastsinn.
3. Nennen Sie drei Farben, die Sie im Raum, draußen oder auf dem Heimweg bemerkt haben.
4. Skizzieren Sie die Form einer Pflanze, einer Tasse oder eines Stücks Obst.
5. Sammeln Sie ein Blatt, eine Busfahrkarte und ein Stück Geschenkpapier und ordnen Sie sie auf einer Seite an.
6. Schreiben Sie ein Geräusch auf, das Sie heute gehört haben, und woher es kam.
7. Wählen Sie ein Foto, das Ihnen gefällt, und beschreiben Sie nur das Licht darauf.
8. Zeichnen Sie den Umriss Ihrer Hand und füllen Sie ihn dann mit einem Muster.

Wenn sich ein Impuls wie eine Aufforderung anfühlt, wählen Sie einen anderen oder gestalten Sie eine Seite ganz ohne Impuls.

## Privat bleiben

Privatsphäre gehört zur Übung dazu. Bewahren Sie das Journal an einem Ort auf, den nur Sie erreichen, und sagen Sie Familie oder Freunden klar, dass es Ihnen gehört. Wenn Sie ein Telefon oder Tablet für digitale Notizen nutzen, verwenden Sie einen Passcode und prüfen Sie, welche Apps auf Ihre Fotos zugreifen können. Wenn Sie ein Journal mit jemandem teilen, entscheiden Sie gemeinsam, was hineinkommt und wer es lesen darf. Niemand sollte gebeten werden, eine Seite zu zeigen, die er nicht zeigen möchte.

## Einfachere Varianten

- **Sitzend oder im Bett.** Bewahren Sie das Journal auf einem Schoßtablett oder Klemmbrett auf, Kleber und Schnipsel in einer kleinen Box.
- **Leichter zu greifen.** Verwenden Sie einen dicken Stift, einen großen Klebestift und eine kindersichere Schere mit abgerundeten Spitzen, oder reißen Sie Papier, statt es zu schneiden.
- **Eingeschränktes Sehvermögen.** Nutzen Sie kräftige Farben, große Stücke und dunkle Stifte auf weißem oder cremefarbenem Papier. Bitten Sie um eine Liste der Impulse in großer Schrift.
- **Weniger Auswahl.** Bieten Sie zwei Papierfarben und einen Impuls an. Legen Sie Kleber und Schnipsel auf den Tisch, bevor Sie anfangen.
- **Kürzer.** Ein Aufkleber, eine Farbe oder eine Zeile ist schon eine vollständige Seite.

## Sicherheitshinweise

- Verwenden Sie einen Klebestift oder ungiftigen Kleber. Vermeiden Sie kleine lose Teile, die verschluckt werden könnten, etwa Perlen oder Knöpfe, wenn jemand im Raum Dinge in den Mund steckt.
- Prüfen Sie die Kanten von Schere und Papier. Reißen Sie das Papier, wenn Schneiden schwerfällt.
- Halten Sie stark duftende Sprays und starke Kleber vom Arbeitsplatz fern, wenn jemand Atembeschwerden oder Allergien hat.
- Verwenden Sie keine Fotos anderer Menschen, es sei denn, sie haben zugestimmt.

## Wenn es nicht klappt

Wenn sich eine Seite schwer anfühlt, lassen Sie sie liegen. Sie können sie umdrehen, in eine Mappe legen oder auf einer neuen Seite zu einem anderen Thema beginnen. Wenn ein Impuls etwas Schmerzhaftes hervorruft, hören Sie auf. Legen Sie das Journal weg und tun Sie etwas Ruhiges und Vertrautes, etwa einen warmen Tee oder einen Spaziergang. Wenn das Gefühl bleibt, wenden Sie sich an eine Person, der Sie vertrauen, oder an eine Beratungsstelle oder Hilfe-Hotline.

Das Spiel [Redewendung vervollständigen](/games/finish-the-saying/) ist eine weitere leichte Möglichkeit, Worte auf eine Seite zu bringen, ohne eine schwere Frage zu stellen. Vor allem aber gilt: Ein Journal darf halb fertig bleiben. Auch das ist ein gutes Ergebnis.

Wenn es Ihnen nicht gut geht oder Sie daran denken, sich selbst zu verletzen, warten Sie nicht. Nutzen Sie den auf dieser Seite angegebenen Krisenweg oder rufen Sie Ihre örtliche Notrufnummer an.
