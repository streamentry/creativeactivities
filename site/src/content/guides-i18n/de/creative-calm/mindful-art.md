Achtsame Kunst ist eine langsame Art, Striche zu setzen. Sie wählen eine einfache Form oder ein Motiv und zeichnen es Stück für Stück, dabei schauen Sie zwischen den einzelnen Linien genau hin. Nichts muss wie etwas aussehen. Es geht um die Aufmerksamkeit, das Tempo und die Materialien, nicht um ein fertiges Bild. Das ist eine kreative Aktivität, keine Therapie. Wenn Sie selbst oder die Person, um die Sie sich kümmern, ein gesundheitliches Anliegen haben, sprechen Sie vor einem neuen Vorhaben bitte mit Ihrer Ärztin, Ihrem Arzt oder einer anderen zugelassenen Fachperson.

## Für wen ist das?

Achtsame Kunst passt zu Erwachsenen, die gern etwas gestalten, sich beim Zeichnen aber unsicher fühlen. Sie passt auch zu Menschen, die Wiederholung, Muster und ruhige Tätigkeiten ohne Eile mögen. Sie können es allein machen oder Seite an Seite mit einer Freundin, einem Freund, einer Partnerin, einem Partner oder einer Person, um die Sie sich kümmern. Es funktioniert am Tisch oder im Bett mit einem Schoßtablett. Das sind Anregungen, keine Diagnose. Manche werden Freude daran haben, andere nicht.

## Was brauchen Sie?

- Einfaches Papier, ein halbes Blatt Druckerpapier oder ein kleiner Skizzenblock
- Einen feinen Stift, einen weichen Bleistift und einen Radiergummi
- Einige Buntstifte oder feine Filzstifte
- Einen kleinen Gegenstand zum Zeichnen, etwa eine Tasse, ein Blatt, eine Muschel oder einen Schlüssel
- Ein Zeichenbrett, falls der Tisch uneben ist oder Sie im Bett zeichnen möchten

Haushaltsgegenstände sind in Ordnung. Nehmen Sie, was Sie haben.

## Wie beginnt man eine langsame Zeichnung?

1. Stellen Sie den Gegenstand in gutem Licht auf den Tisch, nicht weit von sich entfernt.
2. Wählen Sie einen Teil davon, etwa den Rand der Tasse oder den Umriss eines Blattes.
3. Zeichnen Sie sehr langsam und schauen Sie mehr auf den Gegenstand als aufs Papier. Lassen Sie die Linie wandern.
4. Nach ein paar Linien halten Sie inne. Betrachten Sie die Zeichnung und schauen Sie dann wieder den Gegenstand an.
5. Beginnen Sie auf einem anderen Teil des Blattes ein Muster: eine Reihe kleiner Kreise, eine Linie aus Wellen oder ein Raster aus Punkten. Wiederholen Sie dieselbe Form, eine nach der anderen.
6. Fügen Sie Farbe nur hinzu, wenn es Ihnen angenehm ist. Verwenden Sie jeweils eine Farbe und lassen Sie sie einen Bereich füllen.
7. Hören Sie auf, wann Sie möchten. Lassen Sie das Blatt liegen und kommen Sie an einem anderen Tag zurück.

Konturzeichnen, bei dem Sie einen Umriss nachziehen, ohne den Stift abzusetzen, und meist nicht auf das Papier schauen, ist ein guter erster Schritt. Die Karten [Muster zeichnen](/activity/draw-repeating-patterns/) und [Was auf dem Tisch liegt skizzieren](/activity/sketch-what-is-on-the-table/) enthalten druckbare Schritte.

## Was Sie als Nächstes ausprobieren können

- **Wiederholte Formen.** Wählen Sie ein einzelnes Zeichen, etwa eine Schlaufe oder ein kleines Dreieck, und füllen Sie einen Papierstreifen damit. Ändern Sie jeweils nur eine Sache, etwa die Größe oder den Abstand.
- **Langsame Raster.** Zeichnen Sie ein Gitter aus Quadraten und füllen Sie jedes Quadrat mit einem anderen einfachen Zeichen. Niemand muss sie in der Reihenfolge ausfüllen.
- **Farbe nach Flächen.** Legen Sie eine Farbe in einer lockeren Form an, dann eine andere, und lassen Sie die Ränder aufeinandertreffen. Das funktioniert auch gut mit [Aquarell malen](/activity/paint-with-watercolors/).
- **Zeichnen zur Musik.** Legen Sie ein Musikstück auf und lassen Sie jede Linie der Musik folgen. Die Karte [Zu Musik zeichnen](/activity/draw-to-music/) erklärt, wie.
- **Abreiben von Strukturen.** Legen Sie Papier über ein Blatt oder eine strukturierte Fliese und reiben Sie mit der Seite eines Wachsmalstifts darüber. Betrachten Sie das Muster, das sichtbar wird.

## Leichtere Varianten

- **Sitzend oder im Bett.** Legen Sie das Papier auf ein Zeichenbrett oder ein Schoßtablett und halten Sie den Stift in Reichweite.
- **Leichter zu greifen.** Nehmen Sie einen dicken Marker oder umwickeln Sie einen dünnen Bleistift mit Schaumstoffband. Zeichnen Sie große statt kleine Formen.
- **Eingeschränktes Sehen.** Verwenden Sie einen dunklen Marker auf weißem Papier, einen größeren Gegenstand und gutes Licht. Beschreiben Sie die Form laut, während Sie sie zeichnen.
- **Weniger Auswahl.** Bieten Sie einen Stift und ein Muster an und lassen Sie die Farbe weg.
- **Kürzer.** Zeichnen Sie eine Reihe von Formen und hören Sie auf. Zwei Minuten zählen auch.
- **Ein Anfang schon auf dem Blatt.** Beginnen Sie mit einem einfachen, bereits gezeichneten Umriss und ergänzen Sie Linien oder Farbe darin.

## Sicherheitshinweise

- Bewahren Sie Stiftkappen, Bleistiftspitzer und kleine Radiergummis von kleinen Kindern und von Personen fern, die Dinge in den Mund stecken könnten.
- Verwenden Sie abwaschbare Marker und ungiftige Farben und lesen Sie das Etikett.
- Wenn das Halten des Werkzeugs Schmerzen verursacht oder der Griff schwach ist, legen Sie es weg. Probieren Sie ein größeres Werkzeug, eine Handauflage oder einen anderen Tag.
- Arbeiten Sie auf einem sauberen Tisch mit einer Fläche, die durch Tinte oder Wasser nicht beschädigt wird.

## Wenn es nicht klappt

Wenn die Person sich langweilt, müde ist oder kein Interesse zeigt, wechseln Sie zu einem einfacheren Muster oder hören auf. Wenn sie sagt, dass sie nicht zeichnen kann, versuchen Sie es ganz ohne Motiv: Linien, Punkte und Schlaufen, ohne richtig oder falsch. Wenn die Aktivität etwas Schmerzhaftes hervorruft, hören Sie auf, bieten Sie ein warmes Getränk an und machen Sie etwas Vertrautes. Aufzuhören ist ein gutes Ergebnis, und das Blatt bleibt erhalten.

Das Spiel [Ausmalen](/games/coloring/) bietet eine verwandte ruhige Tätigkeit mit fertigen Umrissen und kann ein leichterer Einstieg an einem Tag sein, an dem Zeichnen zu viel erscheint.

Eine Übersichtsarbeit (Scoping Review) des WHO-Regionalbüros für Europa aus dem Jahr 2019 hat mehr als 3.000 Studien ausgewertet und beschreibt Zusammenhänge zwischen künstlerischer Betätigung sowie Gesundheit und Wohlbefinden. Lesen Sie sie als Hintergrund, nicht als Beweis dafür, dass eine bestimmte Aktivität einer bestimmten Person hilft.
