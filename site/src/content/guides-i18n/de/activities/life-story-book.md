Ein Lebensbuch ist ein kleines Album über alltägliche Dinge aus dem Leben eines Menschen: eine Lieblingstasse, die Straße, in der eingekauft wurde, ein Werkzeug, das benutzt wurde. Familien versuchen es oft, indem sie sich hinsetzen und Fragen stellen. Dieser Leitfaden geht einen anderen Weg. Sie gestalten das Buch gemeinsam, eine Seite pro Einheit, indem Sie Dinge anfassen, zeichnen und herstellen. Niemand muss etwas beantworten.

## Warum eine Seite nach der anderen?

Kurze Einheiten passen zu den meisten Menschen, die mit Demenz leben, und eine einzelne Seite ist bereits eine vollständige Einheit. Sie beenden eine Seite, legen das Buch weg, und das ist ein Erfolg. Das Buch wächst über Wochen, nicht in einer einzigen langen Sitzung.

## Was kommt auf eine Seite?

Auf jede Seite gehört eine Sache. Wählen Sie eine davon:

1. **Ein Foto oder eine Zeichnung.** Eine Kopie eines Fotos oder eine schnelle Skizze einer Tasse, eines Stuhls oder eines Fensters.
2. **Eine Abreibung.** Legen Sie ein Blatt, eine strukturierte Fliese oder ein Stück Spitze unter dünnes Papier und reiben Sie vorsichtig mit der Seite eines Wachsmalstifts darüber.
3. **Ein paar Worte.** Eine Bildunterschrift mit höchstens fünf Wörtern, in großer Schrift. „Blaue Küche. Kessel auf dem Herd.“
4. **Ein kleiner Gegenstand.** Ein Band, eine Samentüte oder eine Eintrittskarte. Verwenden Sie eine Kopie von allem, was wertvoll ist, und bewahren Sie das Original sicher auf.

## Fragen zu Dingen, nicht zu Gefühlen

Verwenden Sie diese als Einladungen. Die Person darf jede davon überspringen.

- **Eine Tasse:** „Wenn sie möchte, halten Sie sie hoch und fragen Sie: ‚Was gibt man in eine solche Tasse?‘“
- **Eine Küche:** Mit einem Bild einer Küche: „Was davon würden Sie gern auf dem Tisch haben?“
- **Eine Straße:** Mit einem Bild von Geschäften: „In welches würden Sie zuerst hineingehen?“
- **Ein Werkzeug:** „Wofür würden Sie das benutzen? Zeigen Sie mir, wie Sie es halten würden.“
- **Ein Rezept:** „Gibt es ein Gericht, dessen Duft Sie mögen?“
- **Ein Liedtitel:** „Möchten Sie dieses hören? Sie können mitsummen oder einfach zuhören.“
- **Eine Karte:** „Möchten Sie den Weg zu einem Park zeichnen, den Sie mögen?“

Fragen Sie nie wie in einem Test: Fragen Sie nicht nach Namen oder Daten, fragen Sie nicht, wer eine Person auf einem Foto ist, und sagen Sie nicht, ob eine Antwort richtig ist. Jede Anregung betrifft das Ding vor Ihnen, nicht die Vergangenheit. Eine Seite ist kein Test. Sagt die Person etwas anderes, als Sie erwartet haben, schreiben Sie es so auf, wie sie es gesagt hat.

## Wer bewahrt das Buch auf?

Ein Familienmitglied führt das Buch und schreibt die Bildunterschriften, während die Person auswählt, was auf jede Seite kommt. Das Buch bleibt zu Hause, in einem Ordner mit Klarsichthüllen oder in einer einfachen Kiste, wo die Person es jederzeit herausnehmen kann.

## So gestalten Sie es Schritt für Schritt

1. **Wählen Sie einen Ordner oder eine Kiste** mit ein paar leeren Seiten oder Karten.
2. **Vereinbaren Sie gemeinsam ein erstes Thema.** Wählen Sie einen alltäglichen Gegenstand oder einen Ort.
3. **Gestalten Sie eine Seite in einer Sitzung.** Hören Sie auf, wenn die Person müde wird, auch auf halbem Weg.
4. **Fügen Sie die Seite hinzu und zeigen Sie sie** beim nächsten Besuch, bevor Sie eine neue beginnen.
5. **Lassen Sie Lücken.** Leere Seiten oder Seiten, die unvollendet bleiben, sind in Ordnung.

## Wenn eine Seite Traurigkeit auslöst

Manche Gegenstände und Bilder wecken Traurigkeit. Wenn das passiert, hören Sie auf. Sitzen Sie zusammen und sagen Sie etwas Warmes, zum Beispiel: „Schauen wir uns das einfach einen Moment an.“ Legen Sie die Seite weg und kommen Sie an einem anderen Tag zurück, oder auch gar nicht. Bitten Sie die Person nicht, zu erklären, was sie fühlt, und fügen Sie keine Bildunterschrift dazu hinzu.

## Datenschutz

Die Fotos, Zeichnungen und das fertige Buch bleiben in der Familie. Für das Gestalten des Buchs ist kein Hochladen nötig, und dieser Leitfaden bittet Sie nicht, irgendetwas irgendwohin zu senden. Verwenden Sie Kopien wertvoller Fotos, bewahren Sie Originale sicher auf und fragen Sie die Person, bevor Sie eine Seite mit anderen teilen.
