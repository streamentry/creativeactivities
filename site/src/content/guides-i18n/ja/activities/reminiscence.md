回想とは、過去を一緒に楽しむことを意味します。認知症のある多くの方にとって、数十年前の記憶は、今朝の出来事よりもはっきりしていることがよくあります。写真、慣れ親しんだ物、音楽、物語は、そうした記憶を呼び起こし、分かち合う温かな時間をつくってくれます。守るべき決まりは一つです。これは会話であり、クイズではないということです。

## 回想とは何か、そしてクイズ形式とどう違うのか？

回想とは、写真、物、音楽、動画を通して思い出を分かち合うことで、本人のペースに合わせて行います。[NHS](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/) では、写真、物、動画、音楽の助けを借りて、過去の経験や物語を分かち合うことと説明されています。本やタブレットを使う場合もあります。クイズ形式は違います。正しい答えを言うことを求めるため、楽しみではなく、恥ずかしさにつながることがあります。

[National Institute on Aging](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/dos-and-donts-communicating-person-who-has) は、本人に誰か、または何かを覚えているかどうかを尋ねることを、避けるべきことに挙げています。[Family Caregiver Alliance](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/) は、短期記憶に頼る質問を避け、代わりにより遠い過去について話すことを勧めています。

| 代わりに | こう言ってみる |
| --- | --- |
| 「これを覚えていますか？」 | 「楽しそうな日ですね。そのときのことを聞かせてください。」 |
| 「この人は誰ですか？」 | 「ビーチにいるのはローズおばさんですね。その帽子、素敵ですね。」 |
| 「これは何年頃の写真ですか？」 | 「古いお家ですね。あそこで暮らしていたときは、どんな感じでしたか？」 |
| 「いいえ、それはビルではなくフランクよ。」 | 「楽しそうな方ですね。」 |
| 「それはもう聞きました。」 | 「その話、大好きです。」 |

## 写真について、クイズにせずに話すには？

まず目に入ったものについて話し、そのあとで本人が何か付け加えたくなるような余白を残しましょう。

1. **並んで座る。** アルバムを二人の間に置き、テーブル越しに試すのではなく、一緒に見るようにします。
2. **写真を数枚選ぶ。** アルバム一冊分よりも、良い写真が五枚あれば十分です。大きくて鮮明なプリントが向いています。
3. **人の名前は自分から伝える。** 「これはあなたとお父さんの結婚式の日ですね」と言えば、プレッシャーがなくなります。
4. **細部にコメントする。** 服、車、食べ物、天気、顔。「すごい車ですね。ぴかぴかしていますね。」
5. **誘いかけ、求めない。** 「教えてください」や「何が見えますか？」と言いましょう。沈黙は問題ありません。
6. **本人の話についていく。** まったく別の話を始めたら、その話題に乗りましょう。
7. **心地よいうちにやめる。** 疲れが出てくる前に、アルバムを閉じましょう。

すぐに使える写真の問いかけは、[会話カード](/games/conversation-cards/)をお試しください。ご家族の写真を使ってやさしいマッチングゲームを作るなら、[写真ペア](/games/photo-pairs/)をどうぞ。選んだ写真は、お使いのブラウザ内にとどまります。

## 思い出の箱の作り方は？

思い出の箱とは、本人の人生にまつわる物を入れた箱で、手に取って話題にするためのものです。

1. **開けやすい丈夫な箱を選ぶ。** 靴の箱、帽子の箱、小さな木製の箱などが向いています。
2. **テーマを決めるか、いろいろ混ぜる。** 仕事、趣味、ある場所、ある年代、あるいはそれらを少しずつ。
3. **安全な物を集める。** 始めるには五〜十点で十分です。
4. **大切な物はコピーを使う。** 取り替えのきかない写真や書類はコピーし、原本は安全な場所に保管しましょう。
5. **一度に一つずつ取り出す。** 一つ手渡し、それについて話しかけて、会話がどこへ向かうかを見ましょう。

入れるとよい物の例：

- **仕事：** 名札、小さな道具、制服のワッペン、帳簿、看護師のピン、食堂の料理本。
- **家庭：** 本人の筆跡のレシピカード、ふきん、お気に入りのスカーフやネクタイ。
- **趣味：** 針を外した釣りのルアー、野球のボール、毛糸の玉、種の袋。
- **場所：** 絵はがき、地図、観光土産、故郷の新聞の切り抜き。
- **家族：** 写真のコピー、子どもの描いた絵、結婚式の招待状。

鋭い物、飲み込んでしまうおそれのある小さな物、そして本人が喜ぶとわかっているのでなければ、つらい思い出を呼び起こすかもしれない物は入れないでください。

## ライフストーリーブックの作り方は？

ライフストーリーブックとは、本人の人生の写真と短い説明文をまとめた簡単なアルバムです。一緒に見るためのものであり、訪問者や介護スタッフが、本人の人生全体を知る助けにもなります。

1. **形式を選ぶ。** 透明なシートを入れられるファイル、印刷した写真集、タブレットで見るスライドショーなどがあります。
2. **いくつかの章を決める。** 子ども時代、学校、仕事、家族、住んだ場所、信仰、趣味、好きな食べ物や音楽など。
3. **一ページに写真を一、二枚入れ、** 大きな文字の短い説明文を添える。「メアリー、22歳、銀行で働き始める。」
4. **好みや日課を書き添える。** 「コーヒーはミルク入り。日曜日の讃美歌が好き。大きなテレビの音は苦手。」これは、本人を世話する人にとって役立ちます。
5. **本人が望む分だけ関わってもらう。** 写真を選ぶ、話を語る、あるいはまとまっていくのを眺めるだけでも構いません。
6. **少しずつ足していく。** 完成させなくても役立ちます。

## 回想のそのほかのアイデア

- **若い頃の音楽をかけ、** それが連れていってくれる場所について話す。[音楽のアクティビティ](/creative-calm/music-for-calm-and-connection/)をご覧ください。
- **好きな時代の家庭用の映像やテレビ番組を見る。**
- **子どもの頃の料理を作り、** 香りから話題が広がるようにする。
- **故郷の地図を見て、** 馴染みのある道をたどる。
- **古いカタログや雑誌を手に取り、** 値段、流行の服、車について話す。
- **本人の許可を得て、** 携帯電話で話を録音し、家族のために残す。
- **ビデオ通話の中で分かち合う。** 写真を一枚画面に見せましょう。[電話とビデオ通話](/together/staying-connected-from-afar/)をご覧ください。
- **訪問するときに写真や物を持っていく。** 訪問に話しやすい話題ができます。[訪問](/together/visiting-someone-in-care/)をご覧ください。

## 思い出がつらいときは？

思い出によっては、悲しみ、後悔、恐れを呼び起こすことがあります。本人が動揺したら、話を止め、安心できるようにし、そっと話題や活動を変えましょう。何があったかについて議論しないでください。Family Caregiver Alliance は、本人が間違っていると説得しようとしないよう助言し、本人が示す気持ちに応えるよう勧めています。その気持ちは本物だからです。亡くなった人を生きているかのように話す場合は、その気持ちに応えてください。「あの人が恋しいのですね。その方のことを聞かせてください。」

## 研究は何と言っているか？

回想に関する[コクランのレビュー](https://www.cochrane.org/evidence/CD001120_reminiscence-therapy-dementia)は、22件の試験と1,972人を対象としたもので、効果は一貫しておらず、小さく、場面や方法によって異なることがわかりました。認知症のある人に害が生じたという根拠は見つかりませんでした。回想をお勧めするのは、温かく意味のある時間を一緒に過ごす助けになりうるからであり、治療としてではありません。気軽な会話についてさらに知りたい方は、[診断後の最初の一歩](/caregiving/after-dementia-diagnosis/)をご覧ください。
