回想とは、単純に言えば、過去を一緒に楽しむことです。認知症の方にとって、数十年前の思い出は、今朝のことよりもはっきりと残っていることが少なくありません。写真、なじみのある品物、音楽、昔話は、そうした思い出を開き、温かい会話のきっかけになります。守るべきルールは一つです。これは会話であり、クイズではありません。

## 回想とは何か、クイズとはどう違うのか？

回想とは、写真、品物、音楽、動画を使い、本人のペースに合わせて思い出を分かち合うことです。[NHS](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/)は、写真、品物、動画、音楽などの助けを借りて、過去の経験や物語を分かち合うことと説明しています。クイズはそれとは異なります。本人に正しい答えを出すことを求めるため、楽しさではなく、気まずさを生むことがあります。

[米国国立老化研究所](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/dos-and-donts-communicating-person-who-has)は、誰かや何かを覚えているかどうかを本人に尋ねることを、避けるべき行動に挙げています。[Family Caregiver Alliance](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)は、短期記憶に頼る質問を避け、代わりにもっと昔のことについて話すよう勧めています。

| 避けたい言い方 | 代わりの言い方 |
| --- | --- |
| 「これ、覚えていますか？」 | 「楽しそうな日ですね。そのときのことを聞かせてください。」 |
| 「この人は誰？」 | 「ローズおばさんが海辺にいますね。この帽子、素敵ですね。」 |
| 「これは何年ですか？」 | 「古いお家ですね。あそこで暮らしていたときは、どんな感じでしたか？」 |
| 「いいえ、それはビルじゃなくてフランクよ。」 | 「楽しそうな人ですね。」 |
| 「それはもう聞いたわ。」 | 「その話、大好きです。」 |

## 写真について、クイズにせずに話すには？

まず目に入ったものについて話し、そのあとで、本人が話したければ付け加えられるように余白を残しましょう。

1. **隣に並んで座りましょう。** アルバムを間に置き、テーブルの向こうから試すのではなく、一緒に眺めるようにします。
2. **写真を数枚選びましょう。** 箱いっぱいの写真より、よい写真を五枚ほどの方が良いです。大きくて鮮明なプリントが最適です。
3. **人物の名前は自分から伝えましょう。** 「ここには、結婚式の日のあなたとお父さんがいますね」と言えば、プレッシャーがなくなります。
4. **細部にふれてみましょう。** 服、車、食べ物、天気、表情。「すごい車ですね。ピカピカですね。」
5. **誘いかけるのであって、求めないこと。** 「〜について聞かせてください」や「何が目に入りますか？」。沈黙があっても構いません。
6. **本人の話についていきましょう。** まったく別の話を始めたら、その流れに乗りましょう。
7. **心地よいうちに終わりましょう。** 疲れが出る前にアルバムを閉じましょう。

すぐに使える写真の話題には、[会話カード](/games/conversation-cards/)が役立ちます。ご家族の写真をやさしい組み合わせゲームにしたい場合は、[写真のペア](/games/photo-pairs/)をお試しください。選んだ写真はブラウザの中にとどまります。

## 思い出の箱の作り方は？

思い出の箱とは、ご本人の人生にまつわる品物を入れて、手に取ったり、話題にしたりするための箱です。

1. **丈夫な箱を選びましょう。** 開け閉めしやすい靴の箱、帽子の箱、小さな木箱などです。
2. **テーマを決めるか、いろいろ混ぜましょう。** 仕事、趣味、ある場所、ある時代、あるいは何でも少しずつ。
3. **安全な品物を集めましょう。** 最初は五〜十点ほどで十分です。
4. **大切な品はコピーを使いましょう。** かけがえのない写真や書類はコピーを入れ、原本は安全な場所に保管します。
5. **一度に一つずつ取り出しましょう。** 一つ手渡して、何か一言話し、そこから会話がどこへ向かうかを見守ります。

入れると良いものの例です。

- **仕事：** 名札、小さな道具、制服のワッペン、帳簿、看護師のピン、食堂の料理本。
- **家庭：** ご本人の字で書かれたレシピカード、ふきん、お気に入りのスカーフやネクタイ。
- **趣味：** 針を外した釣りのルアー、野球のボール、毛糸玉、種の袋。
- **場所：** 絵はがき、地図、観光みやげ、故郷の新聞の切り抜き。
- **家族：** 写真のコピー、子どもの絵、結婚式の招待状。

鋭利なもの、飲み込む恐れのある小さなもの、そして、本人が喜ばないと分かっていない限り、つらい思い出につながりそうなものは入れないようにしましょう。

## 人生の本の作り方は？

人生の本とは、ご本人の人生の写真と短いキャプションを集めた、簡単なアルバムです。一緒に眺めるためのものであり、訪問者や介護スタッフが、その人の全体像を理解する助けにもなります。

1. **形式を選びましょう。** シートホルダー付きのバインダー、印刷した写真集、タブレットで見るスライドショーなど。
2. **いくつかの章を決めましょう。** 子ども時代、学校、仕事、家族、暮らした場所、信仰、趣味、好きな食べ物や音楽など。
3. **各ページに写真を一、二枚入れ、** 短く大きめの文字のキャプションを添えます。「メアリー、22歳、銀行で働き始めた頃」
4. **好みや習慣を書き加えましょう。** 「ミルク入りのコーヒーが好き。日曜日の賛美歌が大好き。大きな音のテレビは苦手。」これは、お世話をする人にとって役立ちます。
5. **本人を巻き込みましょう。** 写真を選んだり、話をしたり、ただ完成していく様子を眺めたりと、本人が望む範囲で。
6. **少しずつ足していきましょう。** 完成させなくても、役立ちます。

## 回想のほかのアイデア

- **若い頃の音楽をかけて**、そこからどんな思い出が浮かぶかを話しましょう。[音楽のアクティビティ](/creative-calm/music-for-calm-and-connection/)もご覧ください。
- **お好きな時代のホームムービーやテレビ番組**を一緒に見ましょう。
- **子どもの頃の料理を作り**、香りから会話が広がるのを待ちましょう。
- **故郷の地図を見て**、なじみのある通りをたどりましょう。
- **昔のカタログや雑誌を開き**、値段、流行、車について話しましょう。
- **本人の許可を得て、話を録音し**、家族のために残しましょう。
- **電話や通話の時間に共有しましょう。** ビデオ通話中に写真を一枚見せてみてください。[電話やビデオ通話](/together/staying-connected-from-afar/)もご覧ください。
- **訪問するときに写真や品物を持って行きましょう。** 訪問のときに自然な話題になります。[訪問](/together/visiting-someone-in-care/)もご覧ください。

## つらい思い出が浮かんだら？

思い出の中には、悲しみ、後悔、恐れを呼び起こすものもあります。本人が動揺したら、手を止めて、安心できるように寄り添い、そっと話題やアクティビティを変えてください。何があったのかを言い争わないようにしましょう。Family Caregiver Allianceは、本人の考えが間違っていると納得させようとしないよう助言し、本人が示す感情に応えることを勧めています。その感情は本物です。亡くなった方が生きているかのように話すときは、その気持ちに応えてください。「あの人が恋しいんですね。どんな人だったか聞かせてください。」

## 研究では何が分かっているか？

[回想に関するCochraneのレビュー](https://www.cochrane.org/evidence/CD001120_reminiscence-therapy-dementia)は、22件の試験、1,972人を対象としており、効果は一貫せず、小さく、環境や方法によって異なることが分かりました。認知症の方に害があるという証拠は見つからなかったとしています。回想をおすすめするのは、治療としてではなく、温かく意味のある時間を一緒に過ごせるからです。やさしい会話について詳しくは、[診断後の最初のステップ](/caregiving/after-dementia-diagnosis/)をご覧ください。
