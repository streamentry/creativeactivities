感覚アクティビティは、触れる、香る、聴く、見るという感覚を使います。味覚は除いているので、食べ物として口に入れるものは含みません。柔らかいスカーフに触れる、ミントの香りをかぐ、雨の音を聴くなど、一度に一つの感覚に集中する簡単な体験です。これは創作のアクティビティであり、治療ではありません。いくつかの安全確認をすれば、誰にとってもくつろげる時間になります。嚥下の困難、皮膚の病気、アレルギーなど、ご自身やお世話をしている方に健康上の心配がある場合は、まず主治医や専門の資格を持つ専門家に相談してください。

## どんな人に向いていますか？

感覚アクティビティは、人生のさまざまな段階にある成人に向いています。物に触れるのが好きな人、体力が落ちていて負担の少ない作業を望む人、一日の多くを椅子やベッドで過ごす人にもよく合います。世代をまたいで楽しむこともできます。たとえば、子どもと大人が同じ布のかごに触れるような使い方です。これらは提案であり、診断ではありません。

## 必要なもの

- 物を入れる、かごや箱（すっきりさせたい場合はふたつきのもの）
- 大きくて安全な物：柔らかい布の正方形、木のスプーン、なめらかな石、ハーブの小枝
- 肌が健康で、アレルギーがない場合は、無香料またはごく穏やかなローション
- テレビを消した静かな部屋
- 温かいタオル、一杯の水、そして座るための椅子

## 感覚ごとのアイデア

**触覚**

- **手のマッサージ。** 無香料のローションを少量、手の中で温めてから、手首から指先へ、ゆっくりなでます。手順は[手のマッサージをする](/activity/give-a-hand-massage/)カードにあります。
- **布のかご。** ベルベット、コーデュロイ、フリース、サテン、ウールの大きな布を、なでたり折りたたんだりします。同じ考え方で、残しておける作品にする方法は[触感ボードを作る](/activity/make-a-texture-board/)カードにあります。
- **折る・たたむ。** きれいなタオルやナプキンを折ったり、重ねたり、折り直したりします。[タオルを一緒にたたむ](/activity/fold-towels-together/)カードは、落ち着いて続けられる作業です。
- **温かい布。** 寒い日には、温かく湿らせた布を手に当てます。まずご自身の手首で温度を確かめてください。

**嗅覚**

- **生の香草。** ミント、ローズマリー、バジルの葉を指の間で軽くこすり、それから鼻の近くに持っていきます。
- **台所の香り。** 近くでコーヒーを淹れる、パンをトーストする、オレンジの皮をむく、といった香りです。
- **乾燥したラベンダー。** 縫い閉じた小さなサシェ。作り方は[ラベンダーのサシェを作る](/activity/make-a-lavender-sachet/)カードにあります。

**聴覚**

- **好きな音楽。** 慣れた曲を、穏やかな音量で流します。[心を落ち着かせ、つながるための音楽](/creative-calm/music-for-calm-and-connection/)をご覧ください。
- **自然の音。** 雨、波、鳥の声を、小さな音で流します。
- **シェイカー。** 音楽に合わせて鳴らせる安全なシェイカーは、[密閉型シェイカーを作る](/activity/make-a-sealed-shaker/)カードで作れます。

**視覚**

- **窓からの眺め。** 窓の外の餌台、または通りの眺めです。アイデアは[窓から鳥を眺める](/activity/watch-birds-from-a-window/)カードにあります。
- **色と模様。** [ボタンを色で分ける](/activity/sort-buttons-by-color/)カードを使って、ボタンや布の端切れを色別に分けます。大きなボタンだけを使ってください。
- **花。** [花を一緒に生ける](/activity/arrange-flowers-together/)カードは、生花を触れたり、見たり、香りをかいだりする穏やかな方法です。

## 感覚ボックスの作り方

1. その人の暮らしに結びつくテーマを選びます。海、庭、台所、工房、裁縫などです。
2. 大きくて安全な物を五つか六つ選びます。たとえば、大きな貝殻、木のスプーン、柔らかいスカーフ、密閉したラベンダーのサシェ、なめらかな木のブロックなどです。
3. 小さな部品、とがった縁、ほつれた糸、壊れやすい物がないか、すべての物を確認します。
4. 一度に一つずつ取り出します。手渡し、説明し、その人が自分のペースで確かめられるようにします。
5. 使い終わったら箱をしまい、次に使う前にもう一度物を確認します。

## 高齢の方や認知症のある方と行う場合

感覚アクティビティは、認知症の後期にとくに大切になります。[アルツハイマー協会](https://www.alz.org/help-support/caregiving/stages-behaviors/late-stage)は、この段階では世界を主に感覚を通して体験しており、触れること、音、見ること、味、香りを通して思いやりを伝えられると説明しています。[NHS](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/)は、後期には音楽、物に触れること、手のマッサージなど、感覚に焦点を当てたアクティビティが役立つことが多いと示しています。

正面からゆっくり近づき、相手の名前を呼び、触れる前に確認するか、事前に伝えてください。たとえば「ローションがあります。手をマッサージしましょうか？」のように声をかけます。一度に一つのことだけを提供し、表情がやわらいだり、手の力が抜けたり、微笑んだりするかを見てください。手を引く、顔をしかめる、落ち着きなく動くなどの様子があれば、中止してください。一回の時間は、静かな五分ほどにとどめてください。

## 安全メモ

感覚アクティビティはやさしいものですが、物を口に入れてしまう可能性がある人や、飲み込みに問題がある人には、特に注意すべきリスクがあります。

| リスク | 対処方法 |
| --- | --- |
| 窒息 | 飲み込めないほど大きな物だけを使ってください。箱の中にボタン、ビーズ、硬貨、小さなおもちゃを入れないでください。 |
| 食べ物に見えるもの | 使った後は、ローション、石けん、シャンプー、香水をしまってください。食べ物に見えたり、匂いがしたりするためです。人工の果物は取り除いてください。 |
| アレルギー | 始める前に、ナッツ、ラテックス、ウール、植物、香料へのアレルギーがないか確認してください。 |
| 強い香り | 特に喘息やほかの呼吸の問題がある場合は、強い香水やエッセンシャルオイルを避けてください。穏やかで自然な香りのほうが安全です。 |
| 皮膚 | マッサージの前に、赤み、傷、もろい皮膚がないか確認してください。圧は弱くし、顔をしかめたら中止してください。 |
| 温度 | 温かい布や飲み物は、まずご自身の手首で温度を確かめてください。 |
| とがった物や有害な物 | とがった道具、ガラス、有害な工作用品は使わないでください。 |

## アロマセラピーは役立ちますか？

はっきりと測れるような効果は、おそらくないでしょう。[認知症に対するアロマセラピーのコクラン・レビュー](https://www.cochrane.org/evidence/CD003150_aromatherapy-dementia)では、介護施設に住む708人を対象とした13の研究が見つかりました。研究は小規模で、結果も一致していませんでした。レビューが検討した評価項目では、効果の根拠は見つかりませんでした。相手が庭のラベンダーのような穏やかで慣れた香りを楽しむなら、香りを分かち合うのは良いことです。ただし、それは治療ではありません。

## 刺激を抑えた方法

刺激が多すぎると疲れてしまう人もいます。刺激を抑えた方法では、一つの物、やわらかい明かり、温かい毛布を使い、香りはつけません。一緒に座って、明かりが壁をゆっくり移動するのを眺めたり、なめらかな石を一つ握ったりします。声は小さく保ち、いつでも休めるようにしてください。相手が顔をそむけたり、目を閉じたりしたら、それで一回の時間は十分です。

## うまくいかないときは

相手が不安そうなら、中止し、物をしまい、静かに隣に座ってください。別の日に別の感覚を試したり、一日の別の時間帯にしたりしてみてください。朝のほうがよい人もいれば、夕方の静かな時間を好む人もいます。早めに終えても、それは良い結果です。

[カーム・ブリージング](/games/calm-breathing/)の一時休止は、時間の終わりにふさわしいやさしい方法です。一回ずつゆっくり呼吸するだけで、それ以上何かをする必要はありません。
