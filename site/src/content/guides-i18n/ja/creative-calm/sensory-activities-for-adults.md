感覚アクティビティは、触覚、嗅覚、聴覚、視覚を使います。味覚は含めていないので、食べることを前提にしたものはありません。柔らかいスカーフに触れる、ミントの香りをかぐ、雨の音を聞くなど、一度に一つの感覚に集中する、シンプルな体験です。これは創作的なアクティビティであり、治療ではありません。いくつかの安全確認をしておくと、誰にとってもリラックスできる時間になります。ご本人やお世話をしている方に、飲み込みにくさ、皮膚の病気、アレルギーなど健康面で気になることがある場合は、事前に主治医や資格のある専門家にご相談ください。

## どのような方に向いていますか？

感覚アクティビティは、人生のさまざまな段階にある大人に向いています。ものに触れるのが好きな方、エネルギーが少なくなり負担の少ない作業を望む方、一日の多くを椅子やベッドで過ごす方にもよく合います。子どもと大人が同じ布のかごに触れるなど、世代を超えて楽しむこともできます。これらは提案であり、診断ではありません。

## 必要なもの

- 中身を入れるかごや箱（きれいに保ちたい場合はふたつきのもの）
- 大きくて安全なもの：柔らかい布の正方形、木のスプーン、なめらかな石、ハーブの一枝
- 皮膚が健康で、アレルギーがない場合に限り、無香料で刺激の少ないクリーム
- テレビを消した静かな部屋
- 温かいタオル、水の入ったコップ、座ってもらうための椅子

## 感覚ごとのアイデア

**触覚**

- **手のマッサージ。** 無香料のクリームを少量、手のひらで温めてから、手首から指先へゆっくりとなでます。[手のマッサージをする](/activity/give-a-hand-massage/)カードに手順があります。
- **布のかご。** ベルベット、コーデュロイ、フリース、サテン、ウールなどの大きな布を、なでたり折りたたんだりできます。[質感のボードを作る](/activity/make-a-texture-board/)カードでは、同じ考え方を、残しておける作品にする方法を紹介しています。
- **折りたたみとたたむ作業。** きれいなタオルやナプキンを、折る、重ねる、また折り直すなどして行います。[タオルを一緒にたたむ](/activity/fold-towels-together/)カードは、落ち着いて取り組める作業です。
- **温かいタオル。** 寒い日に、手を温めるための温かく湿らせたタオルです。使う前に、必ず自分の手首で温度を確かめてください。

**嗅覚**

- **生のハーブ。** ミント、ローズマリー、バジルの葉を指の間でそっとこすり、それから鼻の近くに持っていきます。
- **台所の香り。** コーヒーを淹れる香り、パンをトーストする香り、近くでオレンジの皮をむく香りなど。
- **乾燥ラベンダー。** 小さな袋に入れて縫い閉じたサシェです。[ラベンダーのサシェを作る](/activity/make-a-lavender-sachet/)カードに作り方があります。

**聴覚**

- **お気に入りの音楽。** 聴き慣れた曲を穏やかな音量で流します。[落ち着きとつながりのための音楽](/creative-calm/music-for-calm-and-connection/)もご覧ください。
- **自然の音。** 雨、波、鳥のさえずりなどを、小さな音で流します。
- **シェイカー。** [密閉シェイカーを作る](/activity/make-a-sealed-shaker/)カードでは、音楽に合わせて鳴らせる安全なシェイカーの作り方を紹介しています。

**視覚**

- **窓から眺める。** 窓の外の鳥のえさ台、または通りの景色です。[窓から鳥を見る](/activity/watch-birds-from-a-window/)カードにアイデアがあります。
- **色と模様。** [ボタンを色で分ける](/activity/sort-buttons-by-color/)カードを使って、ボタンや布の端切れを色ごとに分けます。大きなボタンだけを選んでください。
- **花。** [花を一緒に生ける](/activity/arrange-flowers-together/)カードは、生花を手に取り、眺め、香りをかぐ穏やかな方法です。

## 感覚ボックスの作り方

1. ご本人の生活に関係するテーマを選びます。海辺、庭、台所、工房、裁縫など。
2. 大きくて安全なものを五、六個選びます。大きな貝殻、木のスプーン、柔らかいスカーフ、密閉したラベンダーのサシェ、なめらかな木のブロックなど。
3. どの品にも、小さな部品、とがった縁、ほつれた糸、壊れやすい部分がないか確かめます。
4. 一度に一つずつ取り出します。手渡して説明し、ご本人が手に取って確かめられるようにします。
5. 終わったら箱にしまいます。次に使う前にも、もう一度品物を確認してください。

## 高齢の方や認知症の方と行う場合

感覚アクティビティは、認知症の進行した段階で特に大切になります。[アルツハイマー協会](https://www.alz.org/help-support/caregiving/stages-behaviors/late-stage)によると、この段階では世界を主に感覚を通じて感じており、触れること、音、視覚、味覚、嗅覚を通じてケアを伝えることができます。[NHS](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/)は、後期の段階では、音楽を流す、ものを手に取る、手のマッサージなど、感覚に焦点を当てた活動が役立つことが多いと述べています。

正面から近づき、名前を呼んでから、触れる前に声をかけてください。たとえば「クリームを持ってきました。手をマッサージしてもいいですか？」のように伝えます。一度に一つずつ提案してください。顔つきがやわらぐ、手の力が抜ける、笑顔になるなどの変化に注目しましょう。体を引く、眉をひそめる、落ち着かない様子が見られたら、やめるサインです。かかわりは五分ほどの穏やかな時間に留めてください。

## 安全に関する注意

感覚アクティビティはやさしいものですが、特に口に物を入れてしまう可能性のある方や、飲み込みにくさのある方の場合は、いくつかの注意点が大切です。

| リスク | 対応 |
| --- | --- |
| 窒息 | 飲み込めないほど大きなものだけを使います。箱の中にボタン、ビーズ、硬貨、小さなおもちゃを入れないでください。 |
| 食べ物に見えるもの | 使用後、クリーム、石けん、シャンプー、香水はしまうか、手の届かない場所に置いてください。見た目や香りが食べ物に似ている場合があります。人工の果物は取り除いてください。 |
| アレルギー | 始める前に、ナッツ、ラテックス、ウール、植物、香料へのアレルギーがないか確認します。 |
| 強い香り | 特に喘息など呼吸の問題がある場合は、強い香水やエッセンシャルオイルを避けてください。穏やかで自然な香りのほうが安全です。 |
| 皮膚 | マッサージの前に、痛み、傷、もろさのある皮膚がないか確認します。やさしい圧をかけ、顔をしかめる場合はやめてください。 |
| 温度 | 温かいタオルや飲み物は、まず自分の手首で温度を確かめてください。 |
| とがった物や有害な物 | 刃物、ガラス、有害な工作材料は使わないでください。 |

## アロマセラピーは役に立ちますか？

測定できるかたちで効果があるとは、おそらく言えません。[認知症に対するアロマセラピーのコクラン・レビュー](https://www.cochrane.org/evidence/CD003150_aromatherapy-dementia)では、介護施設で暮らす708人を対象とした13件の研究がまとめられていました。研究は小規模で、結果も一致しておらず、検討された評価項目では効果を示す根拠は見つかりませんでした。ご本人が、庭のラベンダーのような穏やかで慣れ親しんだ香りを楽しんでいるなら、一緒に香りを楽しむのはよいことです。ただし、治療ではありません。

## 刺激を抑えた方法

刺激が多いと疲れてしまう方もいます。刺激を抑えた方法では、一つのもの、やわらかい照明、温かいブランケットを使い、香りは使いません。一緒に座って、壁を動く光を眺めたり、なめらかな石を一つ握ったりしてください。声は小さく、いつでも休憩できるようにしましょう。ご本人が顔をそむけたり目を閉じたりしたら、それで一回のかかわりは十分です。

## うまくいかないときは

ご本人が落ち着かない様子なら、中止して、道具をしまい、静かに座ってください。別の日、別の感覚、または一日の別の時間帯を試してみてください。朝の時間を好む方もいれば、夜に家が静かになってから行うほうが合う方もいます。早めに終えることも、よい結果の一つです。

[落ち着いた呼吸](/games/calm-breathing/)の時間は、かかわりを穏やかに終える方法です。お互いにゆっくり一回ずつ呼吸し、それ以上何かをする必要はありません。
