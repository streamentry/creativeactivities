認知症のある方とのよいゲームは、勝負のようには見えません。ふたりが近くに座り、絵を指差し、ことわざに笑い、話したいことを話す。その光景こそが目指す姿です。ゲームは、一緒に時間を過ごすためのきっかけにすぎません。

このガイドでは、準備の仕方、ゲームのペースの作り方、「うまくいかない」ときの対応、どのゲームでも簡単にしたり少し難しくしたりする方法、会話への広げ方、そしてやめどきについて説明します。当サイトの[ゲーム](/games/)にも、お手元のカードやパズル、ボードゲームにも使えます。

## 認知症のある方とゲームをするには、どうするのがいちばんよいですか？

達成よりも楽しさに目を向けてください。これは[アルツハイマー協会の活動に関する指針](https://www.alz.org/help-support/caregiving/daily-care/activities)の基本的な考え方です。本人がまだできることを土台にし、始めるのを手伝い、難しい部分はご自身が引き受けてください。害のない活動を批判したり訂正したりすることも避けましょう。

実際には、次のようにします。

- **向かい合わせではなく、隣に座りましょう。** 並んで座れば、画面や机を二人で一緒に見ることができ、手伝うことが見守りではなく協力のように感じられます。
- **一度にひとつのゲームを提案しましょう。** 選択肢がたくさんあると、始める前からテストのように感じられてしまいます。
- **本人のペースに従いましょう。** 自分の順番で絵にふれたい、ひとつの絵について十分間話したい、二回やっただけでやめたい。そういうときは、その日はそれがゲームです。
- **完成した回数ではなく、よい瞬間を数えましょう。** 笑顔、話、穏やかなひとときが、目指す成果です。

## 始める前に、何を準備すればよいですか？

数分の準備で、ゲームそのものへの不満の多くを防ぐことができます。

1. **本人の調子がいちばんよい時間帯を選びましょう。** 米国国立老化研究所（NIA）による[活動の調整に関するガイダンス](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease)は、外出や活動を本人の調子がいちばんよい時間帯に計画するよう勧めています。多くの方にとっては午前中の半ば頃です。夕方の遅い時間は大変なことが多いので、[夕方の落ち着いた活動](/creative-calm/calm-afternoon-activities/)もご覧ください。
2. **部屋を静かにしましょう。** できればテレビやラジオを消し、ドアを閉めます。[家族介護者同盟（Family Caregiver Alliance）](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)は、話しかける前に、雑音や気を散らすものを減らすことを勧めています。
3. **体の快適さを先に確認しましょう。** 飲み物を近くに置き、事前にトイレに行ってもらい、座り心地のよい椅子を用意して、眼鏡や補聴器を着けてもらいます。
4. **部屋の明るさを整えましょう。** 画面に光が反射しない、明るくむらのない照明にすると、絵が見やすくなります。
5. **座る前に、ゲームの準備を済ませておきましょう。** アプリを開き、設定を選び、音量も自分で調整します。そのあとで画面を本人の方に向けてください。役立つようであれば、端末の文字を大きくしてください。
6. **端末を立てて置きましょう。** スタンドやケースで端末を立てておけば、誰かが持ち続ける必要がなく、指差しもしやすくなります。

## 押しつけにならないように、どう誘えばよいですか？

気軽に誘い、断りやすくしておきましょう。次のような声かけがうまく伝わることが多いです。

- 「お庭の絵を見つけたんです。一緒に見ませんか？」
- 「このパズル、手伝ってくれませんか？ 行き詰まってしまって。」
- 「今日は花と鳥、どちらがいいですか？」（自由に答えてもらうより、二つから選ぶほうが答えやすいです）
- 「お姉さんにカードを作っているんです。この色はどちらがいいと思いますか？」

アルツハイマー協会は、友人へのカード作りのように、活動の目的を伝えることを勧めています。理由があると、活動に意味が生まれるからです。手伝いを頼むのも効果的です。本人が役に立っていると感じられるからです。

断られたら、受け入れてください。後で改めて誘うか、別のことを提案しましょう。[断られたときの対応](/caregiving/when-they-say-no/)については、そのガイドでさらに詳しく説明しています。

## ゲームはどのくらいの長さにして、どのくらいのペースで進めればよいですか？

本人にペースを決めてもらい、短いセッションを前提にしましょう。一緒に行うゲームに、根拠に基づく理想の長さはありません。二〜五分の落ち着いたやりとりでも、ひとつの活動として十分です。

- **自然に感じるより長めに待ちましょう。** NIAは、本人が応答するための時間を十分に取り、話をさえぎらないよう勧めています。手助けする前に、心の中で十まで数えてみてください。
- **一度にひとつずつ。** 「絵にふれてください」のような短い指示をひとつ出し、待ちます。説明するよりも見せましょう。タップする場所を指で示してください。
- **自由に休んでかまいません。** 絵について話し始めたら、ゲームは待ってくれます。急ぐ必要はありません。
- **見ているだけでもかまいません。** NIAは、見ているほうを好む人もいると述べています。それもひとつの正当な選び方です。

## 間違えた答えは直すべきですか？

いいえ。何度も優しく訂正されると、よかれと思ってしていても、「あなたはうまくできていない」と伝わってしまいます。アルツハイマー協会は、害のない活動を批判したり訂正したりしないよう勧めています。ゲームでは、ほとんどの間違いは害がありません。

| 言いがちな言葉 | 代わりに |
| --- | --- |
| 「違いますよ。」 | 「このやり方でやってみましょう。」（NIAが挙げている例です） |
| 「合っていませんよ。よく見てください。」 | 何も言わず次の番に進むか、「あ、どちらも赤いですね。」 |
| 「この人が誰か、覚えていますか？」 | 「この絵について教えてください。」 |
| 「それはもうやりましたよ。」 | 「いいですね。もう一度やりましょう。」 |
| 「ほら、わかっているでしょう。」 | 「最後まで見せましょうか？」 |

間違いがはっきりと本人をいらだたせているなら、そっと手助けしてください。正しい絵を指し示す、自分が番を代わる、次の回でゲームを簡単にする、などです。ことわざに面白い間違った結末がついたら、一緒に笑いましょう。本人の結末のほうが、よいこともあります。

## ゲームを簡単にしたり、難しくしたりするには？

活動は、段階の名前ではなく、その日の本人に合わせて調整してください。同じ人でも、朝より夕方にはやさしいバージョンが必要なことがあります。NIAの最初のヒントは、活動を本人ができることに合わせ、本人が達成感を得られるようにすることです。

| ゲーム | やさしくする | 少し難しくする |
| --- | --- | --- |
| [Picture Pairs](/games/picture-pairs/) | 4枚のタイルで始め、絵は見えるままにする | タイルを増やす。心地よければ絵を隠す |
| [Find the Same](/games/find-the-same/) | 2つの選択肢 | 最大4つの選択肢 |
| [Sort Together](/games/sort-together/) | あなたが絵を持ち、本人がかごを指す | 本人が絵とかごの両方を自分でタップする |
| [Picture Puzzle](/games/picture-puzzle/) | 4ピース。最初に絵全体について話す | 9ピース |
| [Finish the Saying](/games/finish-the-saying/) | 結末を見せてから、一緒に言う | タップする前に、本人に結末を言ってもらう |
| [Word Search](/games/word-search/) | 印刷して、一緒にひとつの言葉を探し、その最初の文字を指す | 次に探す言葉を本人に選んでもらう |
| [Coloring](/games/coloring/) | あなたが二色を選び、本人がその中から選ぶ | 本人がすべての色を選ぶ |
| [Conversation Cards](/games/conversation-cards/) | 一緒に絵を眺めるだけ | カードにある自由な問いかけを使う |
| [Photo Pairs](/games/photo-pairs/) | 何度も見てきた家族写真を数枚 | 写真を増やす |
| [Picture Bingo](/games/picture-bingo/) | 参加者それぞれに、付き添う人がつく | 参加者が自分のカードに印をつける |
| [Calm Breathing](/games/calm-breathing/) | ただ座って、一緒に眺める | ゆっくり一緒に呼吸する |

ゲームが難しすぎるサインは、考え込んでいるというより不安そうな長い沈黙、「できない」の繰り返し、端末を押しのける、間違いで動揺する、などです。簡単すぎるサインは、退屈そうにする、「子どもっぽい」と言う、などです。その場合は、そのことを尊重し、単語探しや実際の写真のパズル、昔の仕事に関する写真について話すことなど、大人向けだと感じられるものに切り替えてください。

## ゲームを会話につなげるには？

絵のひとつひとつを話すきっかけとして使い、本人が何を言っても、それを良い答えとして受け止めてください。多くのご家族にとって、これがゲームの一番よい部分です。

- **開かれた、間違いのない問いかけをしましょう。** 「何が見えますか？」「どれがお好きですか？」「このような台所について教えてください。」
- **まずご自身の話をしましょう。** 「祖母もこんな犬を飼っていたんですよ。」あなたの話があると、本人も話しやすくなります。
- **話の流れに従いましょう。** 車の絵から、ドライブ旅行の思い出話になったら、その話こそが活動です。ゲームは一時停止にしておきましょう。
- **事実確認はしないでください。** 回想では、楽しい会話のほうが正確な細部より大切です。前回と話が変わっても、新しいバージョンを楽しみましょう。
- **組み込まれた問いかけを使いましょう。** [Finish the Saying](/games/finish-the-saying/)は、各ことわざの後に話題のきっかけが付いています。[Conversation Cards](/games/conversation-cards/)は、まさにこのために作られています。[Photo Pairs](/games/photo-pairs/)はご家族自身の写真を使うため、豊かな思い出話が生まれやすいです。

さらなるアイデアは、[回想の活動](/activities/reminiscence/)のガイドにあります。診断後のサポートについては、[診断後の最初のステップ](/caregiving/after-dementia-diagnosis/)をご覧ください。

## いつやめればよいですか？

疲れや不機嫌の兆しが見えたら、すぐにやめてください。できれば、少し早めにやめるのがよいでしょう。アルツハイマー協会は、注意力が落ちたり、いらだちが強くなったりしたら、活動をやめるか、別の活動に変えるよう勧めています。

次のようなサインに注意してください。

- あくびをする、体が沈む、目が画面から離れていく
- そわそわする、立ち上がる、帰りたいと言う
- ため息をつく、短い返事しかしない、「私は苦手です」と言う
- ランダムにタップする、端末を押しのける
- 涙ぐむ、いらだつ、急に気分が変わる

上手にやめるには、次のようにします。

- **やさしいことで終えましょう。** 組み合わせられるものをもうひとつだけ用意するか、最後の絵を一緒に眺めます。
- **ご自身のこととして伝えましょう。** 「お茶を一杯いただきたいので、ここで終わりにしませんか？」のように言えば、本人がうまくできなかったとほのめかさずに済みます。
- **体を動かす、または落ち着く活動に移りましょう。** 短い散歩、おやつ、洗濯物をたたむ、音楽などです。
- **温かい言葉をかけましょう。** 「あなたとこれをできて楽しかったです。」「正解したから」ではなく、一緒に過ごした時間を喜ぶ言葉です。

早めに終えること、予定を変えること、ゲームをやめてただ一緒に座っていることは、いずれもよい結果です。

## グループや、ビデオ通話でも遊べますか？

はい。少し追加の準備が必要です。グループでは、人数を少なくし、手助けが必要な方の隣に付き添う人を座らせ、共通の焦点がはっきりしたゲームを選びましょう。[Picture Bingo](/games/picture-bingo/)には、グループ向けの印刷用カードと、画面上の進行役があります。詳しくは[介護施設のグループ活動](/crafts/craft-group-sessions/)をご覧ください。

ビデオ通話では、通話の向こう側にいる人が絵を説明し、部屋にいる人が指差したりタップしたりできます。通話は短く、なじみのある内容にしましょう。[電話やビデオ通話](/together/staying-connected-from-afar/)のガイドにも、さらにヒントがあります。

## ゲームがうまくいかないときは？

日によっては、何をしてもうまくいかないこともあります。それはあなたや本人のせいではありません。ゲームをしまい、別の時間帯にするか、別のゲームに変えるか、ゲームをしないかを選んでください。画面を使わない活動もたくさんあります。音楽、タオルをたたむこと、写真アルバムを眺めること、短い散歩などです。さらに多くのアイデアは、[活動のアイデア](/activities/ideas/)でご覧いただけます。
