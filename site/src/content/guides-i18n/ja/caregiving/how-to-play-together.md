認知症のご本人と過ごすゲームは、勝負事のようには見えません。二人が寄り添って座り、絵を指差したり、ことわざに笑ったり、思いついたことを話したりする、そんな時間です。ゲームは、一緒に過ごす時間のきっかけにすぎません。

このガイドでは、準備の仕方、ゲームのペース配分、何かがうまくいかないときの声かけ、どんなゲームでも易しくしたり少し難しくしたりする方法、会話につなげる工夫、そして終えどきの見極め方を紹介します。当サイトの[ゲーム](/games/)にも、お手元のカードやパズル、ボードゲームにも使えます。

## 認知症のご本人とゲームをするには、どうするのがいいですか？

達成よりも楽しさを大切にしてください。これは[アルツハイマー協会の活動に関するガイダンス](https://www.alz.org/help-support/caregiving/daily-care/activities)が示す基本です。ご本人がまだできることを活かし、始めるきっかけを作り、難しい部分はご自分が手伝い、害のない活動を批判したり直したりしないことが大切です。

実際には、次のようなことを心がけてください。

- **向かい合わせではなく、隣に座りましょう。** 並んで座れば、画面やテーブルを二人で一緒に見られ、手伝うことが見守りではなく協力になります。
- **ゲームは一度に一つだけ勧めましょう。** 選択肢がたくさん並ぶと、始める前からテストのように感じられることがあります。
- **ご本人のペースに合わせましょう。** 絵を好きな順番でタップしたい、一つの絵について十分ほど話したい、二回ほど遊んで止めたい、そのようなご本人の意向が、その日のゲームです。
- **完成した回数ではなく、よい瞬間を数えましょう。** 笑顔、語られたひとつの話、落ち着いた三十分間。それこそが目指すべき成果です。

## 始める前には、どう準備すればいいですか？

数分の準備で、ゲームそのものに原因があると思われがちな混乱の多くを防げます。

1. **ご本人の調子がいい時間帯を選びましょう。** [米国国立老化研究所（NIA）の活動の調整に関するガイダンス](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease)は、外出や活動は、ご本人の調子がもっともよい時間帯に計画するよう勧めています。多くの方にとっては午前中の半ば頃です。夕方は負担が大きいことが多いため、[夕方の落ち着いた活動](/creative-calm/calm-afternoon-activities/)もご覧ください。
2. **部屋を静かにしましょう。** テレビやラジオを消し、できればドアを閉めてください。[Family Caregiver Alliance](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)も、話しかける前に騒音や気が散るものを減らすよう勧めています。
3. **快適さを先に確かめましょう。** 手の届くところに飲み物を用意し、事前にお手洗いを済ませ、座り心地のよい椅子に座ってもらい、眼鏡と補聴器を着けてもらいましょう。
4. **明るさを整えましょう。** 画面に光が反射しない、明るくむらのない照明にすると、絵が見やすくなります。
5. **座る前にゲームを準備しておきましょう。** アプリを開き、設定を選び、音量も自分で調整してください。そのうえで、画面をご本人の方へ向けます。必要であれば、機器の文字を大きく表示する設定にしてもかまいません。
6. **機器を立てて固定しましょう。** タブレットを立てて支えるスタンドやケースがあれば、誰かが持ち続ける必要がなくなり、指差しもしやすくなります。

## プレッシャーをかけずに、どう誘えばいいですか？

誘い方は気軽にし、断りやすくしておきましょう。次のような言葉かけが受け入れられやすいようです。

- 「庭の絵を見つけたの。一緒に見ませんか？」
- 「このパズルを手伝ってくれませんか？ 行き詰まってしまって。」
- 「今日は花と鳥、どちらがいいですか？」（自由に答える質問より、二択のほうが答えやすくなります）
- 「お姉さまにカードを作っているんです。この色はどちらがいいと思いますか？」

アルツハイマー協会は、友人へのカード作りのように、活動の目的を伝えることを勧めています。理由があると、活動に意味が生まれるからです。手伝いを頼むのも効果的です。ご本人が役に立っていると感じられるからです。

断られたら、そのまま受け入れてください。あとで改めて声をかけるか、別のことを提案しましょう。[断られたときの対応](/caregiving/when-they-say-no/)については、当サイトのガイドでさらに詳しく説明しています。

## ゲームはどのくらいの時間続け、どのくらいのペースで進めればいいですか？

ペースはご本人に任せ、短い時間を単位に計画してください。一緒に行うゲームに、科学的根拠に基づいた理想の長さがあるわけではありません。落ち着いた二〜五分でも、立派な活動になります。

- **自然に感じるより長めに待ちましょう。** NIAは、ご本人が応えるまでより多くの時間を与え、途中で遮らないよう勧めています。手を出す前に、心の中で十まで数えてみてください。
- **一度に一つの指示にしましょう。** 「絵をタップしてください」のように短く一つだけ伝えて、待ちます。説明するより見せる方が伝わりやすいので、どこをタップすればよいか指差してください。
- **自由に間をとりましょう。** 絵について話したくなったら、ゲームは待ってもかまいません。急ぐ必要はありません。
- **見ているだけでもよしとしましょう。** NIAは、見ているほうを好む方もいると指摘しています。それもひとつの正当な選択です。

## 間違えたとき、直したほうがいいですか？

直さなくて大丈夫です。何度も優しく直されると、善意からでも「あなたはできていない」と伝わってしまいます。アルツハイマー協会も、害のない活動を批判したり直したりしないよう勧めています。ゲームでは、ほとんどの間違いが害のないものです。

| 言いがちな言葉 | 代わりにこう言ってみましょう |
| --- | --- |
| 「違いますよ。」 | 「こうしてみましょうか。」（NIAが挙げている例です） |
| 「合っていません。よく見てください。」 | 何も言わず次の番にする。または「あ、どちらも赤いですね。」 |
| 「この人が誰か、覚えていますか？」 | 「この絵について教えてください。」 |
| 「それはもうやりましたよ。」 | 「それ、いいですね。もう一度やりましょう。」 |
| 「ほら、わかっているでしょう。」 | 「最後まで見せましょうか？」 |

間違いで明らかにいらだっているようなら、そっと手助けしてください。正しい絵を指し示したり、ご自分の番を代わりに進めたり、次の回にはゲームを易しくしたりしましょう。ことわざが面白い結末になったら、一緒に笑ってください。ご本人の答えのほうが、よい結末かもしれません。

## ゲームを易しくしたり難しくしたりするには、どうすればいいですか？

段階の名前にではなく、その日のご本人に合わせて調整してください。同じ方でも、朝より夕方のほうが簡単なバージョンを必要とすることがあります。NIAがまず勧めているのは、活動をご本人にできることに合わせ、達成感を感じられるようにすることです。

| ゲーム | 易しくする | 少し難しくする |
| --- | --- | --- |
| [絵合わせ](/games/picture-pairs/) | 4枚のタイルから始め、絵は見えたままにする | タイルを増やす。心地よく感じられるなら絵を隠す |
| [同じものを探そう](/games/find-the-same/) | 選択肢は2つ | 選択肢を最大4つまで |
| [いっしょに分類](/games/sort-together/) | 絵はあなたが持ち、ご本人にかごを指差してもらう | 絵とかごの両方を、ご本人が自分でタップする |
| [絵のパズル](/games/picture-puzzle/) | 4ピース。まず絵全体について話す | 9ピース |
| [ことわざの続き](/games/finish-the-saying/) | 結末を見せてから、一緒に言う | タップする前に、ご本人に結末を言ってもらう |
| [ワードサーチ](/games/word-search/) | 印刷して、一つの単語を一緒に探し、最初の文字を指差す | 次に探す単語をご本人に選んでもらう |
| [ぬり絵](/games/coloring/) | 色を二つ選んでおき、その中から選んでもらう | すべての色をご本人に選んでもらう |
| [会話カード](/games/conversation-cards/) | 絵を一緒に眺めるだけ | カードにある自由に答える問いかけを使う |
| [写真の組み合わせ](/games/photo-pairs/) | 大切にしている家族写真を数枚 | 写真を増やす |
| [絵のビンゴ](/games/picture-bingo/) | 一人ひとりの横に手伝う人が座る | 参加者が自分のカードに印をつける |
| [落ち着いた呼吸](/games/calm-breathing/) | 一緒に座って眺めるだけ | ゆっくり一緒に呼吸する |

ゲームが難しすぎるサインは、考え込んでいるというより不安そうな長い沈黙、「できない」の繰り返し、機器を押しのける仕草、ミスで動揺することなどです。簡単すぎるサインは、退屈そうにする、または「子どもっぽい」と言うことです。そうなったら、その気持ちを尊重して、大人向けに感じられるものに切り替えてください。たとえば、ワードサーチ、実際の写真を使ったパズル、ご本人が長く携わってきた仕事の写真について話すことなどです。

## ゲームを会話につなげるには、どうすればいいですか？

絵のひとつひとつを話しかけるきっかけにして、ご本人が言うことを、どんな内容でもよい答えとして受け止めてください。多くのご家族にとって、ゲームの中でいちばん大切なのはこの時間です。

- **答えが決まっていない、開かれた質問をしましょう。** 「何が見えますか？」「どれが好きですか？」「こんな台所で、どんなことを覚えていますか？」
- **まずご自分から話しましょう。** 「祖母もこんな犬を飼っていたんです。」あなたの話があると、ご本人も話しやすくなります。
- **話の脱線についていきましょう。** 車の絵から長距離ドライブの話になったら、その話こそが活動です。ゲームは一時停止しておきましょう。
- **事実確認はしないでください。** 回想の場では、正確な細部よりも心地よい会話のほうが大切です。前回と話の内容が違っても、新しい話として楽しんでください。
- **組み込まれた話のきっかけを使いましょう。** [ことわざの続き](/games/finish-the-saying/)では、各ことわざのあとに話題になる問いかけが出てきます。[会話カード](/games/conversation-cards/)は、まさにこのために作られています。[写真の組み合わせ](/games/photo-pairs/)では、ご家族自身の写真を使うため、豊かな思い出が語られることがよくあります。

さらにアイデアは、[回想の活動](/activities/reminiscence/)に関するガイドにあります。診断を受けた後のサポートについては、[診断後の最初のステップ](/caregiving/after-dementia-diagnosis/)をご覧ください。

## いつ終えればいいですか？

疲れや戸惑いの兆しが見えたら、すぐに、できれば少し早めに終えてください。アルツハイマー協会は、集中力が落ちたり、いらだちが強まったりしたら、活動を止めるか変えるよう勧めています。

次のような兆しに注意してください。

- あくびをする、ぐったりする、画面から目がそれていく。
- そわそわする、立ち上がる、帰りたがる。
- ため息をつく、短く答える、「私には無理」と言う。
- でたらめにタップする、機器を押しのける。
- 涙ぐむ、いらだつ、急に気分が変わる。

うまく終えるためのコツは次のとおりです。

- **簡単なことで締めくくりましょう。** ご本人がうまくできる最後の組み合わせや、最後に眺める一枚の絵で終えます。
- **ご自分の都合にしましょう。** 「お茶を一杯いただきたいので、ここで止めませんか？」と言えば、うまくいかなかったという印象を与えずに済みます。
- **体を動かす活動や、心を落ち着かせる活動に移りましょう。** 短い散歩、おやつ、洗濯物をたたむこと、音楽などです。
- **温かい言葉をかけましょう。** 「あなたと一緒にできて楽しかったです。」「正解したから」ではなく、一緒に過ごした時間そのものを喜ぶ言葉をかけてください。

早めに終えること、予定を変えること、ゲームをやめてただ一緒に座っていることも、すべてよい結果です。

## グループや、ビデオ通話でも遊べますか？

はい。少し準備を加えれば可能です。グループでは、人数を少人数にとどめ、手助けが必要な方の隣に手伝う人が座るようにしてください。また、はっきりとした共通の焦点がある活動を選んでください。[絵のビンゴ](/games/picture-bingo/)には、印刷できるカードと、グループ向けに画面上で読み上げる機能があります。詳しくは[グループ活動](/crafts/craft-group-sessions/)をご覧ください。

ビデオ通話では、通話相手がカードの絵を説明し、同じ部屋にいる人が指差したりタップしたりできます。通話は短く、なじみのあるものにしてください。[電話やビデオ通話](/together/staying-connected-from-afar/)に関するガイドにも、役立つヒントがあります。

## ゲームがうまくいかないときは、どうすればいいですか？

日によっては何をしても響かないことがあります。それはあなたやご本人の責任ではありません。ゲームを片付けて、別の時間帯に試すか、別のゲームにするか、今日はゲームをしないと決めてください。よい活動の多くは画面を使いません。音楽を聴く、タオルをたたむ、写真のアルバムを眺める、短い散歩をするなどです。さらに多くのアイデアは、[活動のアイデア](/activities/ideas/)でご覧いただけます。
