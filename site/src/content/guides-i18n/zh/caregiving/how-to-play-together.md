与认知症人士一起玩的好游戏，看起来并不像比赛。它更像是两个人挨得很近坐着，指着图片，因为一句俗语而笑起来，聊着冒出来的任何话题。游戏只是让大家一起度过时光的一个理由。

本指南介绍如何准备、如何掌握游戏节奏、事情“出错”时该说什么、如何让任何游戏变得更容易或稍微更有挑战、如何把游戏变成聊天，以及何时该停下来。它适用于我们的[游戏](/games/)，也适用于您家里已有的卡片、拼图和棋类游戏。

## 与认知症人士玩游戏，最好的方式是什么？

重点是享受，而不是成绩。这是[Alzheimer's Association关于活动的指导](https://www.alz.org/help-support/caregiving/daily-care/activities)的核心建议：以对方仍然具备的能力为基础，帮助对方开个头，难的部分由您来完成，并且不要批评或纠正无伤大雅的活动。

具体来说就是：

- **坐在对方身边，而不是对面。** 并排坐着，你们都能看到屏幕或桌面，帮忙会更像是合作，而不是监督。
- **一次只提供一个游戏。** 一大堆选择，会让人还没开始就觉得像在考试。
- **顺着对方的意思来。** 如果对方想按自己的顺序点图片，或者就一张图片聊十分钟，又或者玩两轮就停下，那今天的游戏就是这样。
- **数的是美好的时刻，而不是完成的局数。** 一个微笑、一段故事或一段平静的半小时，才是您要找的结果。

## 开始之前该怎样准备？

几分钟的准备，就能避免大多数本来会被归咎于游戏本身的烦恼。

1. **选对方状态最好的时段。** [美国国家老龄研究所（NIA）关于调整活动的指导](https://www.nia.nih.gov/health/alzheimers-caregiving/adapting-activities-people-alzheimers-disease)建议，把外出和活动安排在对方状态最好的时段。对很多人来说，那是上午。傍晚往往更难，参见[傍晚的平静活动](/creative-calm/calm-afternoon-activities/)。
2. **让房间安静下来。** 如果可以，关掉电视和收音机，并关上门。[Family Caregiver Alliance](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)建议，在开口交谈之前，先减少噪音和干扰。
3. **先确认舒适度。** 手边放一杯饮料，提前去一次洗手间，坐一张舒服的椅子，并戴好眼镜和助听器。
4. **把空间照亮。** 明亮、均匀、屏幕上没有反光的光线，能让图片更容易看清。
5. **坐下之前先把游戏准备好。** 先打开游戏、选好设置，并由您自己调好音量，然后再把屏幕转向对方。如果有帮助，可以在设备上开启更大的文字。
6. **把设备支起来。** 用支架或保护套让平板保持竖立，这样就不需要有人一直拿着，指点起来也更方便。

## 怎样不带压力地邀请对方？

邀请要随意，并且很容易拒绝。下面这些说法通常效果不错：

- “我找到了一些花园的图片，要不要和我一起看看？”
- “能帮我看看这个拼图吗？我卡住了。”
- “今天想看花，还是看鸟？”（两个选项比开放式问题更容易回答）
- “我想给你姐姐做一张卡片。这里该用哪种颜色？”

Alzheimer's Association建议说明活动的目的，例如为朋友做一张卡片，因为有了理由，活动才有意义。请对方帮忙也很有效，因为这会让对方觉得自己有用。

如果对方说不，就接受。过一会儿再试，或者换一个活动。我们关于[对方说不时怎么办](/caregiving/when-they-say-no/)的指南有更多介绍。

## 游戏该玩多久，节奏应该多快？

让对方决定节奏，并计划短时间的活动。对于共同玩的游戏，并没有经过证据支持的理想时长。两到五分钟的平静时光，也可以是一次完整的活动。

- **比感觉上自然的时间再多等一会儿。** NIA建议给对方更多时间来回应，并尽量不要打断。在心里默数到十，再去帮忙。
- **一次只做一步。** 给一个简短的指令（“点一张图片”），然后等待。多示范，少解释：用手指着该点的地方。
- **随时可以停顿。** 如果对方停下来聊一张图片，游戏可以等一等，不必急。
- **允许对方只是看。** NIA指出，有些人更喜欢看，这也是一种合理的选择。

## 要不要纠正错误的答案？

不要。即使出于好意，一次次温和地纠正，也会让对方觉得自己做错了。Alzheimer's Association建议不要批评或纠正无伤大雅的活动。在游戏里，几乎所有错误都无伤大雅。

| 不要这样说 | 可以改说 |
| --- | --- |
| “不对，这是错的。” | “我们换个方式试试。”（这是NIA举的例子） |
| “这两张不配对，再看看。” | 什么都不说，直接轮到下一步，或者说“哦，这两张都是红色的。” |
| “你还记得这是谁吗？” | “跟我讲讲这张图片吧。” |
| “这个你刚刚做过了。” | “这个做得很好。我们再来一次。” |
| “来嘛，你明明知道的。” | “要我把结尾给你看看吗？” |

如果错误明显让对方感到沮丧，就悄悄帮忙：指一下正确的图片，自己替对方走一步，或者下一轮把游戏变简单一些。如果俗语被说成了一个好笑的错误结尾，就跟着一起笑。对方说的结尾，说不定比原来的更好。

## 怎样让游戏变得更容易或更难？

根据当天对方的状态来调整，而不是根据某个阶段的标签。同一个人，傍晚可能比上午需要更简单的版本。NIA的第一条建议，就是让活动与对方的能力相匹配，并确保对方感到自己是成功的。

| 游戏 | 让它更容易 | 稍微增加一点难度 |
| --- | --- | --- |
| [图片配对](/games/picture-pairs/) | 从 4 张牌开始，并让图片保持可见 | 增加牌数，或在感觉舒适的情况下隐藏图片 |
| [找相同](/games/find-the-same/) | 2 个选项 | 最多 4 个选项 |
| [一起分类](/games/sort-together/) | 由您拿着图片，对方指出放进哪个篮子 | 对方自己同时点选图片和篮子 |
| [图片拼图](/games/picture-puzzle/) | 4 块拼图，先一起讲讲整张图片 | 9 块拼图 |
| [说完这句话](/games/finish-the-saying/) | 先给出结尾，然后一起说出来 | 先让对方说出结尾，再点击 |
| [找词游戏](/games/word-search/) | 打印出来，一起找一个词，并指出它的首字母 | 让对方自己选择下一个要找的词 |
| [涂色](/games/coloring/) | 您先选两种颜色，由对方在其中挑选 | 颜色全部由对方选择 |
| [话题卡片](/games/conversation-cards/) | 只是一起看看图片 | 使用卡片上开放式的提问 |
| [照片配对](/games/photo-pairs/) | 几张对方很喜欢的家庭照片 | 增加照片 |
| [图片宾果](/games/picture-bingo/) | 每位玩家身边坐一位帮手 | 玩家自己在卡片上做标记 |
| [平静呼吸](/games/calm-breathing/) | 只是坐在一起看着 | 跟着缓慢地呼吸 |

游戏可能太难的迹象：长时间的停顿，看起来是焦虑而不是思考；反复说“我不行”；把设备推开；或者错误让对方难过。游戏可能太简单的迹象：感到无聊，或者说这游戏“幼稚”。如果出现这种情况，请尊重对方的感受，换成更成熟一些的内容，例如找词游戏、一张真实照片的拼图，或者聊聊与对方过去工作有关的图片。

## 怎样把游戏变成聊天？

把每一张图片都当作一个邀请聊天的机会，对方说的任何内容都是好答案。对很多家庭来说，这是玩游戏最好的部分。

- **多问开放式、没有错误答案的问题。** “你注意到了什么？”“你喜欢哪一个？”“跟我讲讲一个像这样的厨房吧。”
- **先分享自己的事。** “我奶奶以前也养过一只这样的狗。”您的故事，会让对方更容易分享自己的故事。
- **顺着话题走。** 如果一张汽车的图片引出了一段公路旅行的故事，那么这段故事本身就是活动。游戏可以先停下来。
- **不要去核对事实。** 在回忆式的交谈中，愉快的交流比准确的细节更重要。如果故事和上一次的不一样，就享受这个新版本吧。
- **用好游戏自带的提示。** [说完这句话](/games/finish-the-saying/)会在每句俗语后面附上一个引出话题的提示，而[话题卡片](/games/conversation-cards/)正是为这种交谈设计的。[照片配对](/games/photo-pairs/)使用您自己的家庭照片，常常能引出最丰富的故事。

更多点子，请看我们的[回忆类活动指南](/activities/reminiscence/)。关于确诊后的支持，请看[确诊后的第一步](/caregiving/after-dementia-diagnosis/)。

## 什么时候应该停下来？

一出现疲倦或烦躁的迹象，就停下来，最好还要提前一点。Alzheimer's Association建议，当注意力下降或挫败感上升时，就停下来或换一个活动。

请留意以下迹象：

- 打哈欠、身体往下缩，或眼神从屏幕上飘走；
- 坐立不安、站起来，或要求离开；
- 叹气、回答很简短，或说“我这方面不行”；
- 随意乱点，或把设备推开；
- 流泪、烦躁，或情绪突然变化。

如何温和地停下来：

- **用一件容易的事结束。** 再让对方完成最后一次配对，或者看一张最后的图片欣赏一下。
- **把原因说成是您自己。** “我想喝杯茶了，我们就在这里停下来，好吗？”这样就不会让对方觉得自己做得不好。
- **换成活动身体或让人安心的事情。** 短暂的散步、吃点零食、叠叠衣服，或听听音乐。
- **说一句温暖的话。** “和你一起做这个，我很开心。”不要夸对方“答对了”，只表达共处时光带来的快乐。

提前结束、改变计划，或者放下游戏、只是静静地坐在一起，都是很好的结果。

## 可以在小组或视频通话中一起玩吗？

可以，但需要多做一点准备。小组人数要少，把帮手安排在需要帮助的人旁边，并选一个有明确共同焦点的游戏。[图片宾果](/games/picture-bingo/)提供可以打印的卡片，也有适合小组使用的屏幕播报。更多内容请看[养老机构小组活动](/crafts/craft-group-sessions/)。

视频通话时，屏幕另一端的人可以描述图片，房间里的人则负责指点和点选。通话时间要短，内容要熟悉。我们关于[电话和视频通话](/together/staying-connected-from-afar/)的指南有更多建议。

## 如果游戏就是不成功，怎么办？

有些日子，什么都引不起兴趣，这并不说明您或对方有什么问题。把游戏收起来，换个时段、换一个游戏，或者干脆不玩。许多好的活动与屏幕毫无关系：听音乐、叠毛巾、翻看相册，或者散个短步。更多点子请看我们的[活动创意](/activities/ideas/)。
