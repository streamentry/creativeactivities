回忆就是一起享受过去的时光。对许多认知症人士来说，几十年前的记忆，往往比今天早上发生的事更清楚。照片、熟悉的物品、音乐和故事，都可以打开这些记忆，让您有一些温暖的东西可以分享。只有一条规则：这是一场对话，绝不是一场测验。

## 什么是回忆，它与测验有什么不同？

回忆是通过照片、物品、音乐或视频来分享过去，并以对方自己的节奏进行。[英国国民医疗服务体系（NHS）](https://www.nhs.uk/conditions/dementia/living-with-dementia/activities/)把它描述为借助照片、物品、视频或音乐，分享过去的经历和故事，可以在一本书里，也可以在平板电脑上进行。测验则不同：它要求对方说出一个正确的答案，这可能带来的是尴尬，而不是快乐。

[美国国家老龄研究所](https://www.nia.nih.gov/health/alzheimers-changes-behavior-and-communication/dos-and-donts-communicating-person-who-has)把询问对方是否记得某件事或某个人，列为应当避免的事情。[家庭照护者联盟](https://www.caregiver.org/resource/caregivers-guide-understanding-dementia-behaviors/)建议避免依赖短期记忆的问题，改为谈论较久远的过去。

| 不要说 | 可以试试 |
| --- | --- |
| “您还记得这个吗？” | “这看起来是个快乐的日子。跟我说说吧。” |
| “这是谁？” | “这是玫瑰姨妈在海滩上。看看那顶帽子。” |
| “这是哪一年？” | “这看起来是老房子。住在那里是什么感觉？” |
| “不对，那不是比尔，是弗兰克。” | “他看起来很有意思。” |
| “您之前已经跟我说过了。” | “我很喜欢这个故事。” |

## 怎样谈论照片，又不变成测验？

先从您看到的东西说起，然后留出空间，让对方在愿意时补充一些内容。

1. **并排坐着。** 把相簿放在两人中间，一起看，而不是隔着桌子考问。
2. **挑几张照片。** 五张好照片，比一整盒照片更好。大而清楚的印刷照片效果最好。
3. **由您自己说出人名。** “这是您和爸爸在婚礼那天的照片”，可以减轻压力。
4. **评论细节。** 衣服、汽车、食物、天气、面孔。“好漂亮的车，看起来闪闪发亮。”
5. **邀请，不要要求。** “跟我说说……”或“您看到了什么？”沉默也没有关系。
6. **顺着对方的话题走。** 如果他完全转到别的事情上，就跟着他走。
7. **在仍然愉快的时候停下。** 在疲倦出现之前，就把相簿合上。

想要现成的图片话题，可以试试[对话卡](/games/conversation-cards/)。想把自己的家庭照片做成温和的配对游戏，可以试试[照片配对](/games/photo-pairs/)；您挑选的照片只会留在您的浏览器中。

## 怎样制作记忆盒？

记忆盒是一个装着对方人生物品的容器，让人可以拿在手上，并围绕它们交谈。

1. **选一个结实的盒子，** 容易打开的，例如鞋盒、帽盒或小木箱。
2. **选择主题或混合的内容。** 工作、爱好、某个地方、某个十年，或各式各样的东西都放一点。
3. **收集安全的物品。** 开始时五到十件就足够了。
4. **珍贵的东西用复制品。** 无法替代的照片和文件，复制一份，并把原件妥善收好。
5. **一次只拿出一件。** 递给对方一件，说一句关于它的话，然后看话题会往哪里走。

可以放进去的东西：

- **工作：** 名牌、一件小工具、制服上的徽章、一本账簿、护士的胸针、餐馆的食谱书。
- **家里：** 他手写的食谱卡、一条茶巾、一条喜欢的围巾或领带。
- **爱好：** 一个没有钩子的钓饵、一个棒球、一团毛线、一包种子。
- **地方：** 明信片、地图、旅游纪念品、家乡报纸的剪报。
- **家人：** 照片的复制品、孩子的画、婚礼请柬。

不要放锋利的物品、可能被吞下的小东西，以及可能勾起痛苦回忆的东西，除非您知道对方乐意接受。

## 怎样制作生平故事册？

生平故事册是一本简单的相簿，收集对方生活的照片，并配上简短的说明文字。它是可以一起翻看的东西，也能帮助访客和照护人员看到这个人的全貌。

1. **选择形式。** 带透明页套的活页夹、印刷的相册，或平板电脑上的幻灯片。
2. **规划几个章节。** 童年、学校、工作、家庭、居住过的地方、信仰、爱好、喜欢的食物和音乐。
3. **每页放一两张照片，** 配上简短、大字的说明：“玛丽，22 岁，开始在银行工作。”
4. **写下喜好和日常习惯。** “咖啡要加牛奶。喜欢周日的赞美诗。不喜欢大声的电视。”这对照顾他的人会很有帮助。
5. **让对方参与，** 参与多少由他决定，可以挑选照片、讲故事，或只是看着它慢慢成形。
6. **持续添加。** 它不必完成，也依然有用。

## 更多回忆点子

- **播放他年轻时的音乐，** 并谈谈这些音乐让他想到了什么。参阅[音乐活动](/creative-calm/music-for-calm-and-connection/)。
- **观看家庭录像或他喜欢的年代的电视节目。**
- **做一道童年时吃的菜，** 让气味带动话题。
- **看看家乡的地图，** 用手指沿着熟悉的街道画线。
- **翻看旧的目录或杂志，** 聊聊价格、时尚和汽车。
- **在征得同意后，用手机录下他的故事，** 留给家人。
- **在通话时分享。** 视频通话时举起一张照片；参阅[电话与视频通话](/together/staying-connected-from-afar/)。
- **探访时带一张照片或一件物品。** 它能让探访有一个容易的焦点；参阅[探访](/together/visiting-someone-in-care/)。

## 如果某段回忆令人痛苦怎么办？

有些回忆会带来悲伤、遗憾或恐惧。如果对方变得激动，请停下来，安慰他，并温和地换个话题或活动。不要与对方争论事情发生的经过。家庭照护者联盟建议，不要试图说服对方他是错的，而是回应他所表达的感受，而这些感受是真实的。如果对方谈到一位已经去世的人，仿佛对方还活着，就回应那份感受：“您很想念她。跟我说说她吧。”

## 研究说了什么？

一项 [Cochrane 回忆疗法综述](https://www.cochrane.org/evidence/CD001120_reminiscence-therapy-dementia)涵盖了 22 项试验和 1,972 人，发现其效果并不一致、幅度较小，并因场所和形式而异。综述没有发现对认知症人士有伤害的证据。我们推荐回忆活动，是因为它能带来温暖、有意义的相处时光，而不是把它当作一种治疗。想了解更多轻松的交谈方式，请参阅[确诊后的第一步](/caregiving/after-dementia-diagnosis/)。
